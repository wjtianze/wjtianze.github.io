6 种输入格式标准化输出自动去重WorkBuddy 技能

支持的输入格式

文档、表格与纯文本
TXT

纯文本

适合每行一个单词，或使用空格、制表符分隔的简洁词表。

CSV

CSV 表格

识别逗号分隔的数据列，保留已有字段并整理标准结构。

XLS

Excel

从 XLSX 工作表读取批量词汇、释义及附加信息。

DOC

Word

解析 DOCX 文档中的列表或表格形式词库内容。

PDF

PDF

提取 PDF 文档中可识别的词汇文本并进行结构化整理。

MD

Markdown

支持 Markdown 列表与表格，适合维护在文本仓库中的词库。

四步完成转换

在 WorkBuddy 对话中使用
01
提供词库
上传文档，或直接在对话中粘贴词库内容。
02
触发技能
说“转换词库”“词库转 JSON”或“格式化单词表”。
03
检查结构
AI 解析字段、拆分多义、保留特殊音标字符并自动去重。
04
导入学习
下载标准 JSON，在天择背单词的词库管理中完成导入。

标准输出结构

清晰、可读、可导入
vocabulary.jsonJSON
[
  {
    "word": "accommodate",
    "phonetic": "/əˈkɒmədeɪt/",
    "pos": "v.",
    "meaning": [
      "容纳；提供空间",
      "迁就；照顾",
      "适应"
    ],
    "examples": [
      {"en": "...", "zh": "..."}
    ],
    "tags": ["CET-6"]
  }
]
01

数组作为顶层

输出使用 [...]，每个单词对应一个对象。

02

多义保持独立

meaning 始终为数组，每条释义单独保存。

03

内容原样保留

音标中的 ə、ˈ、ɒ 等特殊字符不会被替换。

04

重复自动合并

同一单词只保留一条有效记录，避免重复学习项。

转换完成后，进入天择背单词

在“词库管理”中导入生成的 JSON，即可开始四阶段词汇训练。
