vocabulary.json · JSON
[
  {
    "word": "accommodate",
    "phonetic": "/əˈkɒmədeɪt/",
    "pos": "v.",
    "meaning": [
      "容纳；提供空间",
      "迁就；照顾",
      "适应"
    ],
    "examples": [
      {"en": "...", "zh": "..."}
    ],
    "tags": ["CET-6"]
  }
]

数组作为顶层

输出使用 [...]，每个单词对应一个对象。

多义保持独立

meaning 始终为数组，每条释义单独保存。

内容原样保留

音标中的 ə、ˈ、ɒ 等特殊字符不会被替换。

重复自动合并

同一单词只保留一条有效记录，避免重复学习项。
