词库转 JSON

将任意格式的词库文档转化为天择背单词应用的标准 JSON 格式。

功能说明

这是一个 WorkBuddy AI 技能，在 WorkBuddy 对话中触发即可使用。

支持的输入格式

📄
TXT
纯文本，每行一个单词
📊
CSV
逗号分隔表格
📗
Excel
XLSX 工作表
📘
Word
DOCX 文档
📕
PDF
PDF 文档
📝
Markdown
MD 表格

输出格式

[
  {
    "word": "accommodate",
    "phonetic": "/əˈkɒmədeɪt/",
    "pos": "v.",
    "meaning": ["容纳；提供空间", "迁就；照顾", "适应"],
    "examples": [{"en": "...", "zh": "..."}],
    "tags": ["CET-6"]
  }
]

使用方法

  1. 在 WorkBuddy 对话中上传或粘贴词库文档
  2. 说「转换词库」「词库转 JSON」或「格式化单词表」
  3. AI 自动解析并输出标准 JSON 文件
  4. 导入天择背单词应用的「词库管理」→「导入 JSON」

关键规则

  • meaning 必须是数组：一词多义时每义一条，自动按分号/逗号拆分
  • 顶层是数组：[...]，不是对象
  • 自动去重：同一单词只保留一条
  • 音标保留：特殊字符（ə ˈ ɒ）原样保留
💡 提示

转换后的 JSON 可直接导入天择背单词应用使用。
