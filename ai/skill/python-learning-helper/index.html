先确认它是不是你要的

如果教材内容主要是 Python，并且你希望边看概念边运行例子，就选这个版本。它不是一个普通在线代码框：程序由电脑上的 Python 解释器运行，所以文件、命令行参数、交互式输入和错误回溯都更接近真实开发环境。

和普通课本学习助手的区别：普通版适合数学、物理、化学等教材；Python 版在相同学习框架里额外提供代码工作区。只想阅读或做题时，不必打开控制台。

安装与首次启动

  1. 下载 ZIP 后完整解压，不要直接在压缩包预览窗口里运行。
  2. 把解压后的技能文件夹交给 Codex，或放进本机 Codex 的技能目录。
  3. 准备 Windows 10/11、可用的 Python 解释器和已登录 ChatGPT 的 Codex 桌面环境。
  4. 对 Codex 说：“使用 Python 课本学习助手学习这份教材的第 X 章。”随后选择教材文件。

如果电脑里没有可用 Python，生成的学习页仍能阅读和做题，但代码运行区会明确提示缺少解释器。

使用 python-learning-helper-codex 学习这份教材的第 3 章。保留教材全文，知识点要配可操作演示，并为代码题准备可运行测试。

生成一份学习页

生成时会先读取教材章节，再整理知识点、章节摘要、原文、题目和交互演示。Python 题还会单独校验代码、测试输入和预期输出，避免把答案提前塞进题干。

  • 明确教材和章节范围，扫描件先完成文字识别。
  • 保留教材原文，不用摘要替代正文。
  • 每个知识点按需要加入演示；程序概念优先用可运行例子说明。
  • 客观题本地判分，代码题在隔离的本机进程中运行。
  • 生成结束后先运行页面自检，再交付最终 HTML。

编辑器与控制台怎么用

运行普通代码

在编辑器中输入代码，点击运行。标准输出、警告和错误会进入控制台；运行结束后会保存本次代码、时间、退出状态和输出摘要。

使用交互式输入

程序执行到 input() 时，控制台会等待你的输入。输入内容后按回车，程序从原位置继续；不用把所有输入预先写进代码。

逐行调试

需要看变量如何变化时开启逐行调试。可以单步、继续、停止，并在当前行查看局部变量。调试和普通运行互相独立，不会把旧进程留在后台。

文件和参数

运行器支持为程序提供命令行参数和工作目录。访问文件时只在学习包授权的工作区内进行；超过大小上限的文件会被拒绝。

推荐的日常学习顺序

  1. 先看知识点，用演示理解“为什么”。
  2. 回到教材原文核对定义、示例和边界条件。
  3. 把示例改成自己的版本，在控制台运行。
  4. 完成测验；错误自动进入错题本。
  5. 把报错、输出或不理解的代码引用给右侧 Codex 对话，让它只解释当前疑点。
  6. 隔天从错题本和运行历史开始复习。

页面会保存阅读位置、作答、批阅、对话和运行历史。切换章节前不需要手工复制这些状态。

常见问题

点击运行没有反应

先确认学习页是从配套桌面启动器打开，而不是直接双击 HTML；再检查 Python 路径是否可用。

程序一直等待

控制台可能正在等待 input()。查看输入行，提交内容或点击停止。若程序本身是无限循环，也应手动停止。

中文输出乱码

运行器会清理常见环境变量并使用 UTF-8。若第三方程序强制其它编码，请在代码中明确指定文件编码，并避免依赖系统旧代码页。

页面可以读，但 Codex 对话不可用

检查 Codex 是否已登录、App Server 是否能启动，以及模型列表是否返回。学习内容和本地代码运行不会因此丢失。

更新到最新版

  1. 重新下载本站 ZIP，并解压到新目录。
  2. 用新技能生成新的学习页；旧学习页不要直接覆盖。
  3. 如需更新已有学习包，先备份，再让 Codex 使用技能自带的更新脚本迁移。
  4. 更新后运行一次知识点、测验、控制台和交互输入检查。
