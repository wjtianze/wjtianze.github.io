安装和第一次使用

  1. 下载对应 ZIP，完整解压到新文件夹；不要直接在压缩包预览窗口里运行。
  2. 把技能文件夹交给 Codex，或放进本机 Codex 的技能目录。
  3. 准备教材文件，PDF、扫描件或可读取的文档都可以；扫描件会先做文字识别。
  4. 在 Codex 中说明教材、章节和你的重点，技能会生成一份独立 HTML 学习页。
  5. Codex 版按生成包内的启动说明打开；普通接口版可直接用浏览器打开。
使用课本学习助手学习这份教材的第 5 章。保留教材原文，先讲直觉再讲推导，每个知识点都要有能操作的演示。

怎样生成一份好用的学习页

范围说得越明确，生成结果越稳定。一次处理一个章节或一个完整主题；跨越太多章节时，页面会很长，题目和原文也更难核对。

  • 明确教材名称、章节起止和是否包含附录、例题。
  • 说明自己的基础，例如“先补线性代数预备知识”。
  • 指出重点，例如“偏重物理直觉”或“证明步骤不能省”。
  • 要求保留教材原文，不让摘要替代原文。
  • 指定题量、难度和是否需要主观题批阅。

生成结束后会校验知识点索引、六类题型、演示页、引用关系和最终页面。失败时应修正源数据并重新注入，不要在成品 HTML 里手工改一大段数据。

阅读、原文和交互演示

左侧可以在“知识点、教材原文、章节摘要、测验、错题本、批阅数据”之间切换。知识点按一页一个主题组织，先解释核心直觉，再逐步展开公式和例子。

需要观察变化的内容会配交互演示。拖动参数、切换状态或运行步骤后，图形应真实反映概念变化，而不是只播放装饰动画。点击页面中的公式可以复制原始 LaTeX；标题栏的公式助手可按数学、物理、化学和通用类别查找写法。

看不懂时不要只反复读摘要。先操作演示，再回到教材原文核对定义，最后让右侧学习对话解释你卡住的那一步。

测验、判分和错题复习

题型判分方式提交后
单选、判断本地即时判分显示得分和解析
多选、不定项全对满分；只漏选且没有错选得一半标出漏选与错选
填空按标准答案和允许变体判定展示差异与解析
解答提交给学习对话批阅保存评分、评语和改进建议

答错或得分不足的题自动进入错题本。复习时先重新作答，再看旧答案和解析；不要让页面提前显示未作答题目的答案。

右侧学习对话怎么用

可以引用当前知识点、教材段落或题目，再要求解释、举例、出相似题或批阅。多对话彼此分开，切换时保留草稿和历史。

普通接口版

在设置中选择预设或填写兼容接口。接口密钥只保存在当前设备的浏览器存储中；分享学习页前应清除密钥和个人对话。

Codex 版

由配套启动器管理 ChatGPT 登录、模型、思考档位、审批和流式输出。页面不读取账号文件或 Cookie；测试应使用假服务，不消耗真实额度。

请只解释我引用的第 3 个等号为什么成立。先讲直觉，再逐行补全推导，不要直接把后面练习的答案告诉我。

学习记录、备份与迁移

阅读位置、作答、错题、批阅、对话、设置和演示状态默认保存在当前设备。浏览器会按学习页路径区分不同教材；移动或重命名文件后，浏览器可能把它视为新页面。

  1. 更新或移动前先从页面导出学习数据。
  2. 把 HTML、配套资源目录和导出的数据放在一起备份。
  3. 在新位置打开页面后导入数据，核对题目数量和对话。
  4. 对外分享前删除个人作答、对话、接口密钥和不应公开的教材。

常见问题按这个顺序排查

页面空白或按钮失效

确认已经完整解压，并通过本地 HTTP 或配套启动器打开。再尝试页面内的“清除缓存”，避免旧版本状态与新页面结构冲突。

公式没有渲染

检查配套资源是否和 HTML 一起移动，公式是否使用页面支持的 LaTeX 写法。断网时需要保留包内的离线依赖。

演示区域是空的

确认对应演示文件存在，浏览器没有拦截脚本，且不是从压缩包内部打开。演示报错应修复演示源文件后重新生成。

AI对话连不上

普通接口版检查地址、模型、密钥和跨域限制；Codex 版检查启动器、登录状态、模型列表和 App Server 事件日志。阅读与本地判分不依赖 AI，故障期间不会丢失。

什么样的结果才算完成

  • 教材原文完整，知识点能回到原文位置核对。
  • 每个知识点的演示真实编码关键差异，移动端也能操作。
  • 六类题型按规则判分，未作答时不泄露答案。
  • 公式、Markdown、图片和本地链接离线可用。
  • 作答、错题、对话、滚动位置在刷新后恢复。
  • 明亮和深色皮肤都保持足够对比度，不出现白底白字。

更新已有学习包

  1. 先备份现有 HTML、资源目录和导出的学习数据。
  2. 下载新技能到新目录，不覆盖旧技能。
  3. 让 Codex 使用技能自带的更新脚本迁移页面结构。
  4. 重新运行知识点、测验、演示、保存、对话和移动端检查。
  5. 确认无误后再替换旧学习包。

技能更新不应改写你的教材内容、答案或个人学习记录；发现结构不兼容时应保留旧包并报告具体页面。
