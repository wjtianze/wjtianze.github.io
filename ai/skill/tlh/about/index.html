课本学习助手 · 使用教程

VERSION / L7.0 SKILL / textbook-learning-helper 运行方式 / 本地 API 与在线后端

本教程以 API 文档的详细程度，说明 textbook-learning-helper（课本学习助手，简称 TLH）的全部用法：技能如何被触发、生成学习页的六步流程、五个源文件的字段规范、六大题型的输入输出格式、公式与演示的书写规则，以及注入脚本 inject.py 的参数与行为。

请区分两种运行方式：下载后的 L7.0 与 L7.0-d 是自包含的本地 API 技能包，生成时必须由当前用户提供自己的 DeepSeek API Key，生成页会直接调用该接口；两个技能包都不再预置开发者 Key。本站的「在线体验」则走天择后端代理，无需填写或保存 API Key。

1. 触发与生成总览

当用户对 AI Agent 说「学习第 X 节」「帮我整理第 X 章知识点并出题」或类似表述时，Agent 自动调用本技能。整个生成流程分六步，顺序不可颠倒：

  1. 提取教材文本：判断输入是文本型还是扫描/图像型；图像型先 OCR。铁律：fulltext 必须忠实保留全部原文（含例题、注释、表格、公式），不得删减或概括，只允许格式转写。
  2. 创建工作目录 data/ 与 data/demos/。
  3. 分文件写出五类源文件（见第 3 节）：meta.json、fulltext.md、kp.json、questions.json、demos/{ci}_{ii}.html。
  4. 演示强制性铁律：kp.json 里每一个 item 都必须有对应的 demos/{ci}_{ii}.html，inject.py 会校验，缺任何一个都报错退出。
  5. 注入并校验：python3 inject.py data "输出.html" --key sk-你的Key。
  6. 呈现：用 present_files 把生成的 HTML 交付给用户，并提醒用户：本地 API 版分享前必须移除已注入的 API Key。

2. 目录结构

技能包解压后的目录结构：

tlh-L7.0/
├── SKILL.md              # AI Agent 读取的技能说明
├── README.md             # 人类用户阅读的说明
└── references/
    ├── template.html     # 学习页模板（不需要读进上下文）
    ├── inject.py         # 注入与校验脚本
    └── CHANGELOG.md      # 版本更新记录

生成时，AI 创建的工作目录结构如下（data/ 是输入，输出.html 是产物）：

data/
├── meta.json             # 元信息
├── fulltext.md           # 教材全文
├── kp.json               # 知识点（不含 demo 字段）
├── questions.json        # 题目
└── demos/
    ├── 0_0.html          # kpData[0].items[0] 的演示
    ├── 0_1.html          # kpData[0].items[1] 的演示
    ├── 1_0.html          # kpData[1].items[0] 的演示
    └── ...               # 每个知识点都必须有

输出.html                  # inject.py 生成

3. 源文件字段规范

3.1 meta.json 必填

章节元信息，JSON 对象。

字段类型必填说明
bookstring是教材名称。
chapterstring是章节名称。
summarystring是章节摘要，可含公式（$...$）与 加粗。
{
  "book": "大学物理学（自编讲义）",
  "chapter": "狭义相对论基础",
  "summary": "本章介绍……其中洛伦兹因子 $\\gamma=\\dfrac{1}{\\sqrt{1-v^2/c^2}}$。"
}
⚠️ JSON 字符串中的反斜杠必须转义：\dfrac 写作 \\dfrac、\sqrt 写作 \\sqrt。下同。

3.2 fulltext.md 必填

教材全文，规范 Markdown（##/### 标题、段落分行、公式遵守第 4 节规则）。铁律：必须忠实保留全部原文，包括正文、例题、定理证明、注释、表格、公式等，只允许做格式转写（如两栏排版 → 单栏）。

特殊内容高亮：blockquote + 标记开头的段落会自动套上彩色边框样式：

写法效果
> 📖 **定义** ...蓝色边框「📖 定义」
> 📐 **公式** ...橙色边框「📐 公式」（居中）
> 📊 **定理** ...紫色边框「📊 定理」
> 📎 **推论** ...绿色边框「📎 推论」
> 📝 **引理** ...青色边框「📝 引理」
> 💡 **性质** ...粉色边框「💡 性质」
> 📖 **例题** ... 或 > 【例 X.Y】 ...橙色边框「📖 例题」
> 📝 **注释** ...灰色边框「📝 注释」
⚠️ fulltext.md 中不得出现字面量 </script>——它会被拼进 <script type="application/json"> 块，字面量 </script> 会让该块提前关闭、页面崩溃。inject.py 会拦截并报错。

3.3 kp.json 必填

知识点分类数组，不含 demo 字段（demo 由 demos/ 目录单独提供，inject.py 自动组装）。

字段类型必填说明
catstring是分类名。
itemsarray是该分类下的知识点数组。
items[].namestring是知识点名称，可含公式。
items[].descstring是知识点简述，可含公式与 加粗。
[
  {
    "cat": "一、相对论基本原理",
    "items": [
      { "name": "伽利略变换与经典时空观",
        "desc": "经典力学中 $x'=x-vt$、$t'=t$……" },
      { "name": "爱因斯坦两条基本假设",
        "desc": "**相对性原理**与**光速不变原理**……" }
    ]
  }
]

下标约定：demos/{ci}_{ii}.html 中 {ci} 是分类下标（从 0 开始），{ii} 是该分类 items 下标。例如 demos/1_2.html 对应 kpData[1].items[2]。

3.4 questions.json 必填

题目数组，总量建议 6–12 题，六大题型智能搭配。公共字段见下表，各题型差异见第 5 节。

字段类型必填说明
typestring是题型：single / multiple / indeterminate / judge / fill / essay。
textstring是题干，可含公式。选择题题干不含选项。
kpstring是关联的知识点名称（用于薄弱点统计）。
difficultystring是难度：简单 / 中等 / 困难。
explanationstring是解析，可含公式与加粗；选择题逐选项、填空按空、解答按小问讲解。
optionsobject选择题必填选项，键必须是大写字母 A/B/C/D…，严禁 0/1/2/3 数字键。
answerstring/array是参考答案，格式随题型（见第 5 节）。

3.5 demos/{ci}_{ii}.html 每个知识点必填

每个知识点的交互式演示，强制要求。完整 HTML 文档（<!DOCTYPE html> 开头，</html> 结尾），自包含、可在 sandboxed iframe 中独立运行。详细规则见第 6 节。

4. 公式与书写规则

适用于 fulltext.md / kp.json / questions.json：

  • 数学内容一律用 $...$（行内）或 $$...$$（行间），绝不用 \[...\]、\(...\)。
  • 反斜杠命令（\frac、\xi、\vec 等）整体包进 $...$，不裸露在外。
  • 乘号一律用 \cdot，绝不用 \cdotp（会渲染错误）。
  • 长度命令铁律：严禁使用 LaTeX 长度/间距命令——\[4pt]、\[2ex]、\vspace{...}、\hspace{...}、\vskip、\hskip、\smallskip、\medskip、\bigskip、\vfill、\hfill、\newline、\par 等。需要换行就真正换行。
  • 选择题 options 的键必须是大写字母 A/B/C/D…，严禁 0/1/2/3 数字键。
  • 行内公式：仅当含 \sum \int \lim \prod \oint 等大型运算符时才加 \displaystyle；含 \frac 的（除上下标小字外）一律写 \dfrac；上下标内的 \frac 保持原样。
  • 行间公式 $$...$$：不要写 \displaystyle，不要写 \dfrac，分数用 \frac。
  • 生成 JSON 时无需手动加 \displaystyle 或 \dfrac——页面 applyDisplayStyle 函数会自动按上述规则处理。

5. 六大题型输入输出格式

5.1 single 单选

options 键 A/B/C/D；answer 单个大写字母。本地即时判分。

{
  "type": "single",
  "text": "一飞船以 $v=0.6c$ 飞行，飞船钟走 $1\\ \\mathrm{s}$，地面测得历时？",
  "options": { "A": "$0.8\\ \\mathrm{s}$", "B": "$1\\ \\mathrm{s}$",
               "C": "$1.25\\ \\mathrm{s}$", "D": "$1.67\\ \\mathrm{s}$" },
  "answer": "C",
  "kp": "时间膨胀（动钟变慢）", "difficulty": "中等",
  "explanation": "$\\gamma=\\dfrac{1}{\\sqrt{1-0.6^2}}=1.25$，故 $\\Delta t=1.25\\ \\mathrm{s}$，选 C。"
}

5.2 multiple 多选

options 同上；answer ≥2 个大写字母的字符串。漏选但没错选得一半分（partial），完全答对得满分，错选或全错得 0 分。

{ "type": "multiple", "answer": "ACD", ... }

5.3 indeterminate 不定项

options 同上；answer ≥1 个大写字母。漏选但没错选同样得一半分（与多选规则一致）。

{ "type": "indeterminate", "answer": "AC", ... }

5.4 judge 判断

可省 options；answer 写 "对" 或 "错"。

{
  "type": "judge",
  "text": "伽利略变换下 $\\Delta t'=\\Delta t$、$\\Delta x'=\\Delta x$。",
  "answer": "对", "kp": "...", "difficulty": "简单",
  "explanation": "伽利略变换 $t'=t$ 给出时间空间绝对……"
}

5.5 fill 填空

无 options；answer 为参考答案字符串。

{
  "type": "fill",
  "text": "粒子以 $v=0.8c$ 运动，洛伦兹因子 $\\gamma=$ ____。",
  "answer": "1.67", "kp": "...", "difficulty": "中等",
  "explanation": "$\\gamma=\\dfrac{1}{\\sqrt{1-0.8^2}}\\approx 1.67$。"
}

5.6 essay 解答

无 options；answer 为分步参考解答。由 AI（max 思考）按 0–10 评分给评语，可「🔄 重新批阅」。

{
  "type": "essay",
  "text": "杆 $L_0=100\\ \\mathrm{m}$ 以 $v=0.6c$ 运动，求地面测得杆长并说明为何须同时测两端。",
  "answer": "$\\gamma=1.25$，$L=80\\ \\mathrm{m}$。测长度需同一时刻记录两端……",
  "kp": "...", "difficulty": "中等",
  "explanation": "长度收缩公式 $L=L_0/\\gamma$……"
}

6. 演示 HTML 写作规则

适用于 demos/{ci}_{ii}.html：

  • 必须是完整 HTML 文档：<!DOCTYPE html> 开头，</html> 结尾；也接受 HTML 片段（页面会自动包装）。
  • 自包含：所有 CSS 写在 <style> 内，所有 JS 写在 <script> 内；不得引用本地外部文件。
  • </script> 直接写正常的，inject.py 会自动转义为 <\/script> 注入到 JSON 字符串里。绝对不要在演示文件里写 <\/script>（反斜杠转义）。

公式与 Markdown 渲染（自动注入）

页面会自动为每个演示注入 KaTeX（公式）与 marked（Markdown）库，无需手动引入任何 CDN或调用 renderMathInElement：

  • 数学公式：直接用 $...$（行内）或 $$...$$（行间），页面自动用 KaTeX 渲染。
  • Markdown 文字说明：把 Markdown 文本放在带 class="md" 的元素里，页面自动用 marked 渲染（支持标题、列表、表格、代码块、粗体斜体、blockquote 等 GFM 语法）。
  • 动态更新内容后重新渲染：若 JS 动态修改了 .md 元素内容或插入了新的 $...$ 公式，调用 window._demoRender() 重新跑一遍 marked + KaTeX。
  • 不要在演示里重复引入 katex/marked CDN（页面已自动注入，重复引入可能导致冲突）。

其他规则

  • LaTeX 规范：乘号用 \cdot，禁止 \cdotp；禁止 \[ \] 与 \( \)；禁止 LaTeX 长度命令。
  • 必须【交互式】：有滑块、按钮、输入框、下拉框等控件，让学生操作并实时观察结果变化；不能只是静态展示。
  • 视觉美观：现代 CSS（渐变 background、box-shadow、border-radius、平滑 transition）；配色用蓝紫主题（主色 #3a5a9c、强调 #ff7a45、背景 #f4f6fb、文字 #1c2438）；字体 system-ui, -apple-system, "Segoe UI", sans-serif。
  • 布局宽敞：内容居中、padding 充足（至少 16px）、控件间距 8~12px。
  • 不要使用 prompt() / alert() / confirm()（sandbox 限制）；用页面内 DOM 显示反馈。
  • 不要访问 document.cookie、localStorage、parent.xxx（sandbox 限制）。
  • 不要使用 ES module（import/export）——用普通 <script> 即可。
  • 控件必须有初始值，JS 放在 body 末尾的 <script> 里或用 window.onload。

7. inject.py 参数与行为

注入脚本把分开写好的源文件整合后注入 template.html，产出最终学习页。

用法

python3 inject.py <input_dir> <output.html> [template.html] [--key <api-key>]
参数必填说明
<input_dir>是源文件目录（含 meta.json / fulltext.md / kp.json / questions.json / demos/）。
<output.html>是输出 HTML 文件路径。命名格式：技能版本_教材_章节.html（如 L7.0_大学物理_狭义相对论基础.html）。
[template.html]否可选，默认用脚本同目录下的 template.html。
--key <api-key>是（L7.0 / L7.0-d）把模板中的 <your-api-key> 替换为当前用户提供的真实 Key。若模板仍含占位符且未传此参数，脚本报错退出；两个技能包均不预置开发者 Key。

脚本流程

  1. 读取并校验所有源文件（meta / fulltext / kp / questions / demos）。
  2. 强制演示校验：每个 kpData[ci].items[ii] 必须有 demos/{ci}_{ii}.html，缺任何一个报错退出。
  3. 自动把 demo HTML 中的 </script> 转义为 <\/script>（JSON 字符串层面），AI 写演示时可用正常的 </script>。
  4. 组装成完整 data 对象 {book, chapter, summary, fulltext, kpData, questions}。
  5. 拦截 fulltext / kp / questions 中可能残留的字面量 </script>。
  6. 注入 API Key（若需要）。
  7. 把模板中 id="learning-data" 的 <script> 块整体替换为真实数据。
  8. 写出文件，打印 ✅ 已生成：…（知识点 N 个 / 演示 N 个 / 题目 M 道）。
校验失败会非零退出并打印原因——据此回到对应源文件修数据即可。

8. 输出格式（最终 JSON 结构）

inject.py 组装后注入模板的 <script type="application/json" id="learning-data"> 块，结构如下：

{
  "book": "教材名",
  "chapter": "章节名",
  "summary": "摘要（可含公式与 **加粗**）",
  "fulltext": "教材全文（Markdown）",
  "kpData": [
    { "cat": "分类名",
      "items": [
        { "name": "知识点名", "desc": "简述",
          "demo": "交互式演示 HTML 代码（已转义）" }
      ] }
  ],
  "questions": [ { "type": "...", "text": "...", ... } ]
}

9. 页面功能（生成后自动具备）

  • 五视图两栏布局：左栏 tab 切换「知识点 / 教材原文 / 测验 / ❌ 错题本 / 批阅数据」，右栏 AI 对话；列宽可拖动。教材原文视图有「📑 目录」浮层按章/节跳转。
  • 知识点单页：一页一个知识点，顶部「上一个 / 目录 / 下一个」导航。每个含文字、公式、交互式演示（强制）、可选 AI 详解。演示在 sandboxed iframe 中独立运行，支持编辑/重跑/AI 编辑/全屏。
  • 测验单页：一屏一题，「上一题 / 答题卡 / 下一题」切换；底部「🔄 再出几道题 / 📝 批阅本题 / ✅ 全部批阅」。答题卡圆形彩点（白=未做、蓝=做了没批、绿=对、红=错、黄=半对）。单选/多选/不定项可右键排除选项。
  • 错题本：自动收集已批阅但未全对的题目，支持「重新作答」「跳到测验」。
  • 批阅数据：总分、全对数、答题概览表、错题订正建议、薄弱知识点排名。
  • DeepSeek 聊天：V4 Flash / V4 Pro，思考强度（无/high/max）、理解强度（无/标准/深度）。多对话管理、自动命名（≤7 字）、流式输出与中途停止、重新生成与编辑。max_tokens 拉满到 384000。
  • 出题模式：勾选后发送消息自动加 #出题 指令，AI 以 JSON 数组出题并写入题库。
  • AI 详解 / 重写纠错：知识点与已批阅题目可一键生成详解；可让 AI 检查事实/公式/Markdown 错误并改正。
  • 引用知识点/题目：「📎 引用」按钮勾选任意知识点与题目作为本次提问上下文（仅本次有效）。
  • 公式点击复制 LaTeX：点击页面内任意公式复制其 LaTeX 源码（交互元素内的公式除外）。
  • LaTeX 公式助手弹窗：四学科 tab（通用/数学/物理/化学）× 难度，点击即复制，支持搜索。
  • Markdown + KaTeX 渲染：答案/解析/AI 回复/作答/看法/评语均完整渲染，行内公式智能判断 \displaystyle 与 \dfrac。
  • Token 统计与余额：按模型分桶显示用量与计价，精确到 ¥0.00001；右栏显示当前对话费用、累计费用、API 余额（60 秒缓存）。
  • 状态持久化：作答/批阅/对话（含草稿）/设置/滚动位置/索引/demo 代码均存入 localStorage（与文件路径绑定）。左上角「🗑 清除缓存」一键清除。

10. 注意事项与常见错误

  • 知识点与题目务必写进各自源文件（kp.json / questions.json），不要写进 JS 字符串/数组——公式里的 \xi、\underline 在 JS 字符串中是非法转义。
  • 演示 HTML 文件里直接写正常的 </script>，inject.py 会自动转义。不要在演示文件里写 <\/script>。
  • fulltext.md / kp.json / questions.json 中不得出现字面量 </script>——inject.py 会拦截并报错。
  • 不要在生成的 Markdown 中使用 LaTeX 长度命令（\[4pt]、\vspace、\hspace 等），会破坏渲染。
  • 仅针对下载后生成的本地 API 页：注入的 DeepSeek API Key 会随 HTML 分发，分享前必须删除（在文件中搜索 var KEY='sk- 即可定位）。本站在线体验不注入、保存或暴露任何 API Key。
  • 若打开后页面为空或行为异常：点页面左上角的「🗑 清除缓存」按钮清掉所有 localStorage 后重载。
⚠️ 本地 API 页的 Key 提醒：这条提醒只适用于下载后用 --key 生成的 L7 页面。分享前请先用文本编辑器打开，找到 var KEY= 那一行，把引号内的 Key 值删除或替换为空字符串；本站在线体验没有这个字段，也不需要用户提供 Key。

11. AI 能力要求

运行本技能需要至少达到 Claude Sonnet 4.6 水平的 AI。经实测，DeepSeek V4 Flash 和 Claude Haiku 4.5 运行效果较差，不推荐使用。
