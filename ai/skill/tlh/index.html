课本学习助手 TLH

把教材某章/节生成一个可离线打开、可与 DeepSeek 对话的交互式 HTML 学习页——两栏布局，左栏切换「知识点 / 教材原文 / 测验 / 错题本 / 批阅数据」五个视图，右栏是 AI 对话；每个知识点强制附交互式演示。

版本 L7.0 开发者 物竞天择 协议 完全开源 依赖 DeepSeek API

功能定位与适用场景

课本学习助手（textbook-learning-helper）是一个让 AI 分析教材（含数理化 PDF / 扫描件）、提取指定章节知识点并生成可离线打开的交互式 HTML 学习页的技能。它把「读教材—理知识点—做题—对答案—问 AI」这条完整学习闭环，浓缩进一个自包含的 HTML 文件里。

1
自学理工科教材（数学、物理、化学等）：把一章变成带交互演示的知识点 + 题库，比单纯啃书更主动。
2
期末复习 / 章节精练：测验一题一屏，答题卡 + 错题本自动收集错题，AI 批阅主观题并给出评语。
3
教师 / 助教：批量为学生生成某章节的课后练习与讲解页。
4
开发者：在技能基础上二次开发、定制功能（完全开源，含商业用途）。

更多细节见使用教程
🗂️

五视图两栏布局

左栏切换知识点 / 教材原文 / 测验 / 错题本 / 批阅数据，右栏 DeepSeek 对话；列宽可拖动。

✏️

六大题型 + 判分

单选/多选/不定项/判断/填空/解答；客观题本地判分，主观题 AI 批阅；多选漏选但没错选得一半分。

🎮

交互式演示

每个知识点强制附 HTML+JS 交互演示，sandboxed iframe 渲染，自动注入 KaTeX + Markdown。

🤖

DeepSeek 对话

V4 Flash / V4 Pro，可调思考强度与理解强度，支持出题、AI 详解、AI 重写纠错、引用知识点。

∑

公式 + LaTeX 助手

全程 Markdown + KaTeX 渲染；点击任意公式复制 LaTeX 源码；标题栏 LaTeX 助手弹窗按学科 × 难度分类。

💾

状态持久化

作答 / 批阅 / 对话 / 滚动位置 / demo 代码全部存入 localStorage，刷新回到原位；Token 统计与余额查询。
