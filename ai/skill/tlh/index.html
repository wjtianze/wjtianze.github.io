课本学习助手 TLH

把教材章节生成一个可离线打开、可与 AI 对话的交互式 HTML 学习页。知识点、教材原文、测验、错题本、批阅数据与交互演示都在同一工作区。

版本 L7.0 完全开源 DeepSeek API 离线 HTML
LEARNING LOOP

功能定位与适用场景

课本学习助手会分析教材（包括数理化 PDF 与扫描件）、提取指定章节知识点并生成自包含的交互式 HTML，把“读教材—理知识点—做题—对答案—问 AI”浓缩为一个文件。

自学理工科教材

把数学、物理、化学等章节变成带交互演示的知识点与题库。

期末复习与章节精练

一屏一题，答题卡与错题本自动收集结果，AI 批阅主观题。

教师与助教

批量生成指定章节的课后练习、演示与讲解页。

开发者二次开发

基于完全开源的模板与注入脚本定制功能，包括商业用途。

CAPABILITIES

核心功能

更多细节见使用教程

五视图两栏布局

左栏切换知识点 / 教材原文 / 测验 / 错题本 / 批阅数据，右栏 DeepSeek 对话；列宽可拖动。

六大题型 + 判分

单选/多选/不定项/判断/填空/解答；客观题本地判分，主观题 AI 批阅；多选漏选但没错选得一半分。

交互式演示

每个知识点强制附 HTML+JS 交互演示，sandboxed iframe 渲染，自动注入 KaTeX + Markdown。

DeepSeek 对话

V4 Flash / V4 Pro，可调思考强度与理解强度，支持出题、AI 详解、AI 重写纠错、引用知识点。

公式 + LaTeX 助手

全程 Markdown + KaTeX 渲染；点击任意公式复制 LaTeX 源码；标题栏 LaTeX 助手弹窗按学科 × 难度分类。

状态持久化

作答 / 批阅 / 对话 / 滚动位置 / demo 代码全部存入 localStorage，刷新回到原位；Token 统计与余额查询。
