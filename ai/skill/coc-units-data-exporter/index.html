本地数据技能 · 可复现流水线

COC 单位数据 导出器

一套针对《部落冲突》的本地数据工作流：从 APK 提取完整单位数据，也能解析村庄存档、计算剩余升级时间并输出中文报告。

18.400.22 数据源 源码可查 apk_data_pipeline.py village_parser.py
用途

这个技能做什么

本技能包含两个独立可用的 Python 脚本：apk_data_pipeline.py 给定一份《部落冲突》APK，先验证 Android v2/v3 签名，再完成解码、解析、命名映射和导出，产出 单位完整数据.json；village_parser.py 读取你的游戏内账号 JSON，结合前者的数据计算普通升级与超级充能的剩余时间。

全程本地运行。脚本不会下载 APK、不会访问账号、不会联网或自动安装依赖；默认名称表随技能包提供。
能做什么

核心功能

一条命令完成全部提取

全量单位覆盖

兵种、法术、英雄、战宠、英雄装备、建筑、陷阱、守卫与帮手共 273 条；包含 16 组有效超级充能及反击卡组。

所有等级数值

共 3491 行逐级数据与 42 件装备；生命值、伤害、升级花费与时间、所需大本营等级和技能均结构化输出。

中文介绍

从 APK 内置本地化文件提取每条单位的中文介绍文本，无需手动翻译，直接可用。

名称表可替换

内置默认名称表覆盖家乡村庄、建筑大师基地与都城精选项目；也可用 --roster-xlsx 提供自定义表。

无联网无密钥

纯本地解析，不调用 coc.py 静态目录或外部 API，不读取凭据。缺少依赖时明确停止，不会自行联网安装。

结构化输出

标准 JSON 格式，含 meta 元信息与 units 列表，可直接被网页、App、数据分析工具消费。

流水线 01

从 APK 导出完整数据

Python 3.10+

下载技能包解压后，按 requirements.txt 安装密码学依赖，然后运行提取脚本：

PowerShell / 终端
# 只读解析并验证签名，不写文件
python apk_data_pipeline.py --apk "你的APK文件路径.apk"

# 生成 JSON
python apk_data_pipeline.py --apk "APK.apk" --output "单位完整数据.json"

# 使用自定义精选名称表
python apk_data_pipeline.py --apk "APK.apk" --roster-xlsx "名称表.xlsx" --output "单位完整数据.json"

脚本会读取 APK 内的数值表与简体中文本地化，显式解析每张表的等级列，并输出带文件散列、签名证书、数据聚合散列和统计摘要的 单位完整数据.json。

流水线 02

解析村庄存档

village_parser.py

输入从游戏导出的村庄存档 JSON，脚本会结合 单位完整数据.json，输出村庄概况、家乡村庄与建筑大师基地完整清单，以及各类单位达到当前大本营满级的剩余升级时间。

PowerShell / 终端
# 第一个参数是账号 JSON，第二个参数是本流水线生成的游戏数据
python village_parser.py "村庄存档.json" "单位完整数据.json"

脚本内置装备与帮手的 ID 到中文名映射，并正确处理建筑大师基地兵种等级不连续的情况。也可以前往 村庄存档分析 在线体验，或在 升级规划器 用甘特图排程。
