COC 单位数据 导出器

一套针对《部落冲突》的本地数据工作流：从 APK 提取完整单位数据，也能解析村庄存档、计算剩余升级时间并输出中文报告。

v18.400.9 数据源 完全开源 coc_pipeline.py village_parser.py
PURPOSE

这个技能做什么

本技能包含两个独立可用的 Python 脚本：coc_pipeline.py 给定一份《部落冲突》APK，自动完成提取、解密、解析、命名映射和导出，产出覆盖全部单位的 单位完整数据.json；village_parser.py 读取你的村庄存档 JSON，结合前者的游戏数据，按家乡与夜世界分类输出村庄完整信息，并计算各类单位达到当前大本营满级的剩余升级时间。

全程本地运行。两个脚本都内置默认名称表与 ID 映射，不需要账号、API Key 或联网服务。
CAPABILITIES

核心功能

一条命令完成全部提取

全量单位覆盖

兵种、法术、英雄、战宠、英雄装备、建筑、陷阱、守卫、帮手等全部单位类型，共 272 条，含夜世界单位与超级兵。

所有等级数值

每个单位每级的生命值、DPS、伤害、升级花费与时间、所需大本营等级、装备技能等，全部结构化输出。

中文介绍

从 APK 内置本地化文件提取每条单位的中文介绍文本，无需手动翻译，直接可用。

名称表可替换

内置默认名称表覆盖家乡/夜世界/都城全部单位；也可提供自定义 xlsx 覆盖，灵活适配游戏版本更新。

无联网无密钥

纯本地解析，不调用任何外部 API，不读取凭据，不联网。只需 APK 文件即可运行。

结构化输出

标准 JSON 格式，含 meta 元信息与 units 列表，可直接被网页、App、数据分析工具消费。

PIPELINE 01

从 APK 导出完整数据

Python 3.10+

下载技能包解压后，安装 sc_compression 与 openpyxl，然后运行提取脚本：

PowerShell / Terminal
# 基本用法（使用内置名称表）
python scripts/coc_pipeline.py "你的APK文件路径.apk"

# 指定自定义单位名称表
python scripts/coc_pipeline.py "APK.apk" "名称表.xlsx"

# 指定输出目录
python scripts/coc_pipeline.py "APK.apk" "名称表.xlsx" "输出目录/"

脚本会自动从 APK 中提取并解密 91 张数值表与本地化文件，解析宽表结构，匹配单位名称，输出 单位完整数据.json。技能包内附 references/data_structure.md 说明内部结构与解析规则。

PIPELINE 02

解析村庄存档

village_parser.py

输入从游戏导出的村庄存档 JSON，脚本会结合 单位完整数据.json，输出村庄概况、家乡与夜世界完整清单，以及各类单位达到当前大本营满级的剩余升级时间。

PowerShell / Terminal
# 基本用法（默认读取同目录 ../data/all_game_data_zh.json）
python scripts/village_parser.py "村庄存档.json"

# 指定游戏数据文件路径
python scripts/village_parser.py "村庄.json" "单位完整数据.json"

脚本内置装备与帮手的 ID 到中文名映射，并正确处理夜世界兵种等级不连续的情况。也可以前往 村庄存档分析 在线体验，或在 升级规划器 用甘特图排程。
