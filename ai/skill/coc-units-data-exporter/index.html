COC 单位数据 导出器

从《部落冲突》APK 中提取全部单位（兵种、法术、英雄、战宠、装备、建筑、陷阱等）的完整游戏数据，输出结构化 JSON——每条单位含中文介绍、所有等级的数值、所需大本营等级与装备技能。

技能名 coc-units-data-exporter 版本 v18.400.9 数据源 开发者 物竞天择 协议 完全开源

这个技能做什么

给定一份《部落冲突》APK 安装包，技能会自动完成提取、解密、解析、命名映射、导出五步，产出一份覆盖全部单位的 单位完整数据.json。 它内置一份默认单位名称表，开箱即用；你也可以用自己的名称表覆盖。

核心功能

一条命令完成全部提取
📦

全量单位覆盖

兵种、法术、英雄、战宠、英雄装备、建筑、陷阱、守卫、帮手等全部单位类型，共 272 条，含夜世界单位与超级兵。

🔢

所有等级数值

每个单位每级的生命值、DPS、伤害、升级花费与时间、所需大本营等级、装备技能等，全部结构化输出。

🇨🇳

中文介绍

从 APK 内置本地化文件提取每条单位的中文介绍文本，无需手动翻译，直接可用。

🛠️

名称表可替换

内置默认名称表覆盖家乡/夜世界/都城全部单位；也可提供自定义 xlsx 覆盖，灵活适配游戏版本更新。

🔓

无联网无密钥

纯本地解析，不调用任何外部 API，不读取凭据，不联网。只需 APK 文件即可运行。

📄

结构化输出

标准 JSON 格式，含 meta 元信息与 units 列表，可直接被网页、App、数据分析工具消费。

怎么用

下载下方技能包解压后，安装依赖（Python 3.10+，需 sc_compression、openpyxl），然后运行提取脚本： 

# 基本用法（使用内置名称表）
python scripts/coc_pipeline.py "你的APK文件路径.apk"

# 指定自定义单位名称表
python scripts/coc_pipeline.py "APK.apk" "名称表.xlsx"

# 指定输出目录
python scripts/coc_pipeline.py "APK.apk" "名称表.xlsx" "输出目录/"

脚本会自动从 APK 中提取并解密 91 张数值表与本地化文件，解析宽表结构，匹配单位名称，输出 单位完整数据.json。技能包内附 references/data_structure.md 详细说明 APK 内部结构与解析规则。
