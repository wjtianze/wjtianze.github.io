粘贴村庄 JSON

将游戏中导出的村庄 JSON 粘贴到下方文本框，点击「解析数据」即可。解析结果会自动保存到本地，升级规划器与伤害计算器可直接读取；数据仅在浏览器中处理。

剩余升级时间总览

基于当前大本营等级，逐级累加每项单位从当前等级到当前大本营允许最高等级的升级时长。墙钟时间＝该资源串行总时长 ÷ 对应建筑工人或升级设施的并行栏位数。

可选加成：

分工：实验室升级兵种、法术和攻城机器；战宠小屋升级战宠；建筑工人升级英雄、建筑、陷阱和其它项目。已满级或尚未解锁的单位不计入；城墙升级无时间成本，不计入。
