基于村庄存档数据，用甘特图规划升级排程。家乡与夜世界分开，支持稳本 / 速本两种模式，自动把每项升级安排到对应资源最早空闲的时段，支持拖拽微调与冲突校验。

规划模式

分工：研究员（实验室）升级兵种 / 法术 / 攻城机器；战宠研究员升级战宠；建筑工人升级英雄 / 建筑 / 陷阱 / 其他。甘特图每条泳道的进度条数量 = 该资源工人/研究员数量。拖动色块可调整开始时间，系统自动校验同槽位冲突并吸附到最近合法位置。仅当前大本营已解锁的等级可被纳入。
