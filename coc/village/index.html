粘贴你的部落冲突村庄 JSON 数据，自动解析并按「家乡」与「夜世界」分类展示完整村庄信息，计算各类单位到达当前大本营满级的剩余升级时间（含按工人数量折算的墙钟时间）。所有解析在浏览器本地完成。

村庄概况

剩余升级时间总览

基于当前大本营等级，逐级累加每项单位从当前等级到当前大本营允许最高等级的升级时长。墙钟时间＝该资源串行总时长 ÷ 对应工人/研究员数量（即并行后实际所需时间）。

可选加成：

分工：研究员（实验室）升级兵种 / 法术 / 攻城机器；战宠研究员升级战宠；建筑工人升级英雄 / 建筑 / 陷阱 / 其他。已满级或尚未解锁的单位不计入；城墙升级无时间成本，不计入。
