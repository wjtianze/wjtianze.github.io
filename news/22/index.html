天择OS 3.1 发布：悬浮窗修复、命令行重构、COC 工作台

🗓 发布：2026-07-22 ✍ 作者：天择网

天择OS 3.1 是一次聚焦「修 bug + 重新整理」的版本。3.0 上线后，几个体验问题被集中修复，命令行按用途重新拆分，COC 专区也改成了更顺手的形态。（本页已于 07-23 更新：补充 3.1 修订版内容——实用工具全面本地化、村庄存档分析并入 COC 首页、AI 对话 agent 式命令交错、悬浮窗与主对话互通。）

〇、3.1 修订版（07-23）：七项改进

  • 实用工具全面本地化：COC 专区、升级规划、伤害计算、背单词不再实时连接线上天择网，全部作为本地页面打包进天择OS（桌面版通过内置协议加载）。存档直接同源写入：村庄 JSON 存 localStorage、词库存 IndexedDB，OS 命令行与工具页面即时互通，离线也能用。
  • AI 悬浮窗修复 + 与主对话互通：修复悬浮窗执行 words/coc-game 等命令报 failed to fetch（悬浮窗此前没有桌面桥接且数据路径错误），修复词库读取永远返回示例数据（词库结构升级后读取键未同步）。OS 对话窗口与悬浮窗现在共享同一份对话记录：工具栏新增 🔄 同步按钮，并每 4 秒自动同步；深度思考、自定义/豆包选择、截图开关则各自独立，互不干扰。
  • 村庄存档分析并入 COC 首页：独立「村庄分析」应用下线，其完整分析界面（村庄概况、剩余升级时间总览、家乡/夜世界分类）直接搬进 COC 专区首页，旧链接自动跳转。
  • 升级规划/伤害计算修复：修复首页浅存档与工具读取冲突导致的「建筑工人 NaN、夜世界丢失、槽位失效」；修复建筑工人小屋按座数导入（此前 5 座只算 1 座）。
  • AI 命令行模式不再限 3 轮：取消单轮对话最多 3 次命令的限制（仅保留防失控保险）；「调用了 N 条命令行」卡片从对话底部改为内联在所属回答下方——思考过程 → 回答 → 命令卡片 → 思考 → 回答……像标准 agent 工具一样交错展示。
  • 联系开发者页修复：修正页面 hero 占满全屏、内容被挤出首屏的问题，现在一屏展示全部联系方式。
  • 稳定性修复：修复 3.1 初版清空对话/切换开关时可能栈溢出的隐藏递归。

一、AI 悬浮窗：四项修复

  • 只留一个关闭按钮：之前顶栏和配置栏各有一个关闭按钮，现在只保留顶栏那个，不再重复。
  • 清空对话修复：根因是悬浮窗里调用的 refreshOpenApp('ai-chat') 找不到对应窗口（悬浮窗不是 ai-chat 应用），清空后界面不刷新。现在改用统一的 refreshChatView()，悬浮窗模式下重新渲染整个对话区。
  • 切换豆包修复：同样是刷新失效导致切不动，修复方式同上。
  • 记忆状态：关闭悬浮窗时记住位置与大小，下次打开恢复原样（桌面版持久化到本地文件，网页版存 localStorage）。对话内容本就共享，无需额外处理。

二、天择OS 系统修复与精简

  • 时钟不再走 1 秒就停：根因是用了已废弃的 DOMNodeRemoved 事件，窗口内容刷新时会误触发清除定时器。改为每秒自检「自身是否还在 DOM 里」，不在就停。
  • 天择网系列应用精简：开始菜单的「天择网」分类只保留「天择网主页」和「天择导航」两个入口，其余板块（新闻/博客/AI 专区等）通过天择导航树或主页访问。
  • COC 专区与背单词归入「实用工具」：它们会自动读取本地保存的玩家村庄 JSON 和词库并填入——因为天择OS、COC 页面、背单词页面同源，浏览器 localStorage 与 IndexedDB 本就共享，无需额外接口。

三、命令行：按用途拆分

  • coc-data：改为读写本地玩家村庄存档。coc-data 看摘要，coc-data json 输出原始 JSON，coc-data save <JSON> 保存，coc-data clear 清除。
  • coc-game（新）：查询游戏静态数据（兵种/建筑/法术等）。coc-game search 名字、coc-game th 等级、coc-game cat 类别、coc-game json 输出原始数据。
  • words：导入单词时支持例句——words add 单词|词性|释义|英文::中文，多个例句用 || 分隔。
  • 浏览器 ↗ 按钮：改为在系统外（系统默认浏览器）打开当前网址，而不是在 OS 内新开标签页。

四、COC 专区主页：村庄存档分析工作台

COC 专区主页即「村庄存档分析」工作台：顶部是「数据查询 / 升级规划 / 伤害计算」三个导航按钮；下方粘贴村庄 JSON 后，即时输出村庄概况（大本等级、工人数量、待升级任务）、剩余升级时间总览（含按工人数折算的墙钟时间）与家乡/夜世界分类明细，并自动保存到本地（升级规划器、伤害计算器与 coc-data 命令直接读取同一份存档）。

五、天择OS 官网与联系开发者

  • 官网改为电脑端 / 网页端 / 更新日志三栏布局，不再提供历史版本下载，想下载历史版本请联系开发者。
  • 全站页眉最右侧新增「联系开发者」入口，附 QQ 与邮箱。站内意见箱已有计划，但需要买服务器，会视使用人数决定是否开发。

六、升级方式

网页版下次启动自动获取 3.1；桌面版请前往天择OS 入口下载 3.1 安装包覆盖安装。修订版更换了桌面版本地页面加载协议（首次启动如看不到旧数据：在旧版「系统设置 → 存档管理」导出存档，再到新版导入即可完整迁移，AI 配置、对话、软件、词库都在其中）。
