天择OS 3.1 发布：悬浮窗修复、命令行重构、COC 工作台

🗓 发布：2026-07-22 ✍ 作者：天择网

天择OS 3.1 是一次聚焦「修 bug + 重新整理」的版本。3.0 上线后，几个体验问题被集中修复，命令行按用途重新拆分，COC 专区也改成了更顺手的工作台形态。

一、AI 悬浮窗：四项修复

  • 只留一个关闭按钮：之前顶栏和配置栏各有一个关闭按钮，现在只保留顶栏那个，不再重复。
  • 清空对话修复：根因是悬浮窗里调用的 refreshOpenApp('ai-chat') 找不到对应窗口（悬浮窗不是 ai-chat 应用），清空后界面不刷新。现在改用统一的 refreshChatView()，悬浮窗模式下重新渲染整个对话区。
  • 切换豆包修复：同样是刷新失效导致切不动，修复方式同上。
  • 记忆状态：关闭悬浮窗时记住位置与大小，下次打开恢复原样（桌面版持久化到本地文件，网页版存 localStorage）。对话内容本就共享，无需额外处理。

二、天择OS 系统修复与精简

  • 时钟不再走 1 秒就停：根因是用了已废弃的 DOMNodeRemoved 事件，窗口内容刷新时会误触发清除定时器。改为每秒自检「自身是否还在 DOM 里」，不在就停。
  • 天择网系列应用精简：开始菜单的「天择网」分类只保留「天择网主页」和「天择导航」两个入口，其余板块（新闻/博客/AI 专区等）通过天择导航树或主页访问。
  • COC 专区与背单词归入「实用工具」：它们会自动读取本地保存的玩家村庄 JSON 和词库并填入——因为天择OS、COC 页面、背单词页面同源，浏览器 localStorage 与 IndexedDB 本就共享，无需额外接口。

三、命令行：按用途拆分

  • coc-data：改为读写本地玩家村庄存档。coc-data 看摘要，coc-data json 输出原始 JSON，coc-data save <JSON> 保存，coc-data clear 清除。
  • coc-game（新）：查询游戏静态数据（兵种/建筑/法术等）。coc-game search 名字、coc-game th 等级、coc-game cat 类别、coc-game json 输出原始数据。
  • words：导入单词时支持例句——words add 单词|词性|释义|英文::中文，多个例句用 || 分隔。
  • 浏览器 ↗ 按钮：改为在系统外（系统默认浏览器）打开当前网址，而不是在 OS 内新开标签页。

四、COC 专区主页：实时存档分析工作台

COC 专区主页重构为两行布局：上面一行是「数据查询 / 升级规划 / 伤害计算」三个导航按钮；下面一大行左边是村庄 JSON 输入框，右边是实时分析结果——粘贴 JSON 即时显示大本等级、建筑/兵种/英雄/法术数量与建筑列表，并自动保存到本地（与村庄分析页、coc-data 命令共享同一份数据）。

五、天择OS 官网与联系开发者

  • 官网改为电脑端 / 网页端 / 更新日志三栏布局，不再提供历史版本下载，想下载历史版本请联系开发者。
  • 全站页眉最右侧新增「联系开发者」入口，附 QQ 与邮箱。站内意见箱已有计划，但需要买服务器，会视使用人数决定是否开发。

六、升级方式

网页版下次启动自动获取 3.1；桌面版请前往天择OS 入口下载 3.1 安装包覆盖安装，本地存档不丢失。
