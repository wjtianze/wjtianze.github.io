天择OS 上线并开源：浏览器里运行的 AI 操作系统

🗓 发布：2026-07-14 ⏰ 时间：12:30（UTC+8） ✍ 作者：天择网

天择网推出了一个全新项目：天择OS——一个在浏览器中全屏运行的模拟操作系统。它不是天择网的又一个子页面，而是一个独立的、沉浸式的操作系统体验，部署在 wjtianze.github.io/os，与天择网共享同一套紫-蓝-绿配色，但拥有完全独立的界面与交互体系。

它是什么

天择OS 用纯前端技术模拟了一个完整的桌面操作系统：开机动画、桌面图标、任务栏、窗口管理、开始菜单、右键菜单、通知中心——这些标准 OS 元素都在浏览器里被重新实现。打开它就像启动一台虚拟电脑，但它不需要安装任何东西，打开网页就能用。

天择网的所有功能被预装为系统应用：新闻、博客、数据开源、AI 专区、COC 数据查询、村庄分析、升级规划器、绩点战争游戏，都变成桌面上的图标，双击就能在窗口里打开。你不再需要通过导航栏来回切换页面，而是像使用真正的电脑一样，同时打开多个窗口。

核心：AI 代码生成引擎

天择OS 最特别的地方是软件商城。你只需要用一句话描述你想要的软件——比如"一个贪吃蛇游戏"或"一个番茄钟计时器"——AI 会先帮你把模糊的想法优化成一份清晰的软件规格，然后直接生成完整的可运行代码，并自动安装到桌面上。

生成的软件在一个安全的沙箱窗口中运行，不会影响系统本身。你可以随时打开、关闭或卸载它们。所有生成的软件都保存在你的浏览器本地，下次打开天择OS 时依然存在。

此外还有AI 对话应用，可以像使用普通 AI 助手一样与它聊天、问问题、写代码，对话历史会自动保存。

桌面风格：PC 与移动端自适应

天择OS 会自动检测你的设备类型。在电脑上，默认呈现 Windows 风格的桌面（底部任务栏 + 桌面图标网格），也可以一键切换为 macOS 风格（顶部菜单栏 + 红黄绿窗口控制按钮）。在手机上，则会自动切换为类似 iOS 的主屏 + 底部 Dock 布局，应用全屏打开，底部保留 Home 条手势区。

窗口支持拖拽移动、八方向缩放、最小化、最大化、关闭。任务栏显示所有正在运行的应用，可以点击切换。开始菜单支持应用搜索。桌面和图标都支持右键菜单。

数据全在本地

天择OS 不依赖任何服务器。你的 AI 配置（API Key）、已安装的软件、对话历史、桌面偏好，全部通过浏览器 localStorage 保存在你自己的设备上。关闭浏览器、重启电脑，数据都还在。当然，这也意味着清理浏览器数据会清空天择OS——请在「系统设置」中谨慎使用重置功能。

AI 功能需要你自行配置一个 OpenAI 兼容的 API 接口。我们内置了 DeepSeek、OpenAI、硅基流动、智谱 GLM 等常用服务的预设，填入自己的 Key 即可。你的 Key 只保存在本地，不会经过天择网的服务器。

现已开源

天择OS 的全部源代码已在天择网「数据开源」板块开放下载——三个文件、约 2700 行、纯前端单文件架构，无任何后端依赖。任何人都可以免费下载、查看、学习、修改、二次开发，用于任何目的，无需署名、无需告知。窗口管理、AI 对话与代码生成引擎、软件商城、桌面系统、多风格主题、浏览器应用等全部模块均含完整中文注释，清晰可读。
