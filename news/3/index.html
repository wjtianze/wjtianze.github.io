COC 专区上线，游戏数据查询可在线使用

🗓 发布：2026-07-09 ⏰ 时间：18:35（UTC+8） ✍ 作者：天择网

天择网今天上线了「COC 专区」——一个面向《部落冲突》（Clash of Clans）玩家的兴趣板块。专区的第一个功能是游戏数据查询，把整理好的静态游戏数据搬到了网页上，支持分类浏览和关键词搜索，点击任意条目还能查看各等级的详细数值。

查询哪些数据

本次导入的数据覆盖九大类别，共 260 余条：

  • 兵种（97 条）：野蛮人、弓箭手、飞龙、皮卡超人……含生命值、伤害、人口、移动速度等属性。
  • 建筑（76 条）：防御、军队、资源、城墙等各类建筑，含生命值、伤害、升级费用与时间。
  • 法术（19 条）、英雄（7 条）、宠物（11 条）、装备（35 条）、陷阱（12 条）、守卫（2 条）、助手（3 条）。
每条数据都附带中英文名称、简介，以及完整的等级数值表（建造/升级费用、时间、所需大本营等级、生命值、伤害等）。

怎么用

进入 COC 专区 → 游戏数据查询，页面顶部提供搜索框和分类标签：

  • 分类筛选：点击顶部标签在「全部 / 兵种 / 法术 / 英雄 / 宠物 / 装备 / 建筑 / 陷阱 / 守卫 / 助手」之间切换。
  • 关键词搜索：在搜索框输入中英文名称或关键字，实时过滤结果。
  • 查看详情：点击任意卡片，弹出详情面板，展示完整基础属性和各等级数值表。

关于数据来源与隐私

需要特别说明两点：

  • 纯静态数据：所有数据来自本地整理的 JSON 文件，不调用任何外部接口，也不查询玩家或部落信息。这里只查「兵种有多强」「建筑要多少资源」这类游戏设定数据。
  • 无需任何密钥：本功能是纯前端页面，不涉及任何 API Key 或登录，打开即用。

接下来

这是 COC 专区的第一个功能。数据查询已经覆盖了核心玩法元素，后续如有新的整理需求或数据补充，会在这里继续更新。欢迎前往 游戏数据查询 试试，或从 COC 专区首页 进入。
