天择OS 2.6 发布：窗口置顶、文档缩放与命令行全面扩展

🗓 发布：2026-07-20 ✍ 作者：天择网

天择OS 2.6 聚焦"窗口层级"、"文件阅读"与"命令行生态"三个高频场景：任何软件窗口都可以一键置顶到最上层，文档阅读器迎来了完整的缩放能力，命令行则把每个自有软件都接了进来。

一、窗口置顶：四种方式，随你喜欢

现在你可以把任意窗口固定在最上层，即使点击其他窗口，它也不会被压下去。天择OS 提供了四种操作方式：

  • 标题栏图钉按钮：每个窗口标题栏新增一枚图钉，点一下置顶，再点一下取消。
  • 标题栏右键菜单：在标题栏空白处右键，选择"置顶窗口"或"取消置顶"，同时还能快速最小化、最大化、关闭。
  • 任务栏右键菜单：右键任务栏上正在运行的应用图标，选择"置顶窗口"或"取消置顶窗口"。
  • 命令行：打开命令行终端，输入 pin 应用id、top 应用id、unpin 应用id，或 pinned 查看当前所有置顶窗口。AI 命令行模式也已同步支持这些命令。

置顶窗口会自动获得紫色高亮边框，层级独立于普通窗口。本次同步修复了 2.6 首发版本中"置顶窗口层级过高、遮挡任务栏与快捷面板"的问题——现在置顶窗口始终位于任务栏、开始菜单与快捷面板之下，不会再挡住系统操作区。

二、文档阅读器缩放：像专业阅读器一样看文件

文档阅读器新增完整的缩放工具栏，支持 PDF、Word（docx）、PPT（pptx）、Excel（xlsx）、HTML、txt、markdown 全部格式：

  • ± 按钮：工具栏左侧缩小、右侧放大，每次 10%。
  • Ctrl + 滚轮：在阅读区域按住 Ctrl 滚动鼠标滚轮，即可快速缩放，习惯与浏览器一致。
  • 自定义百分比：在工具栏输入框直接输入 10%–500% 的任意数值，回车生效。
  • 页宽填充：让内容宽度刚好填满阅读区域，适合阅读文字为主的文档。
  • 整页填充：让完整一页同时适应阅读区域的宽和高，适合快速预览整页排版。

每个打开的标签页独立记忆自己的缩放方式，切换标签时工具栏会自动同步当前文档的缩放状态。

三、命令行全面扩展：每个软件都有自己的命令

2.6 把"自有软件"全部接入了命令行：每个内置与预装应用都有自己的顶层命令，无需 cmd 前缀，输入 help 即可一键查找全部用法。命令行引擎也升级为支持异步命令（fetch / IndexedDB），终端与 AI 命令行模式均已适配。

3.1 数据类命令：直接输出，不再打开应用

  • coc-data 输出 COC 中文数据摘要（含版本、单位总数、分类统计、单位列表），不再打开应用
  • coc-data search 野蛮人 按中英文名搜索单位详情（HP/DPS/升级花费/所需大本）
  • coc-data th 13 列出大本 13 级可解锁的所有单位
  • coc-data cat 圣水兵 按类别过滤；coc-data count 仅看分类统计
  • coc-json 输出 COC 原始 JSON 完整数据（约 2MB，终端会自动折叠）
  • words 输出当前单词本 JSON（同源时读 IndexedDB 真实词库，跨域时回退示例词库）
  • words add hypothesis|n.|假设 添加单词；words list 20 列出前 20 个；words count 计数；words find 关键词 查找；words del 编号 删除

3.2 软件直达与信息查询命令

  • AI 对话：chat clear|history|last 清空 / 看历史 / 看 AI 最后回复
  • 软件商城：store open|tutorial|idea 打开 / 教程 / 创意建议
  • 我的软件：files list|export 应用id|size 已安装列表 / 导出 HTML / 大小
  • 系统设置：settings info|storage|reset 系统信息 / 存储 / 重置布局
  • 关于：about info|changelog|credits 详情 / 更新日志 / 致谢
  • 浏览器：browser tabs|closeall|home 标签页 / 全关 / 主页
  • 玩机技巧：tips 列出全部，tips 3 查看第 3 条详情
  • 天择导航：tree 看分类，tree system 看该分类下应用
  • 文档阅读器：docs open URL|recent 在线打开 / 最近记录

3.3 天择网专区直达

  • 主页：home sections|open 板块
  • 新闻 / 博客：news 与 blog 自动 fetch 列表，news 5 打开第 5 条
  • COC 专区：coc list|open 专区板块与入口
  • 村庄分析 / 升级规划 / 伤害计算：village / planner / dmg 各自的 info 与 open；dmg quake 5000 4 还能直接告诉你"4 瓶地震必毁城墙"
  • 游戏专区：game list|open 与 gpa info|open|rules 查看绩点战争规则
  • 英语 / AI / 数据开源：english / ai-zone / open-data 各自的 list 与 open
  • 模拟器：emu-win / emu-win10 / emu-android 的 info 与 open

用户安装的 AI 软件仍可用 cmd 应用id 指令 调用各自注册的命令包（cmd list 查看全部）。AI 命令行模式的提示词也已同步更新，AI Agent 可以直接调用上述所有命令。

网页版用户下次启动天择OS 即自动获取 2.6；桌面版用户请前往天择OS 入口获取新版安装包（首次安装或覆盖升级均可，本地存档不会丢失）。
