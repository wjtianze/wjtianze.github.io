天择OS 2.5 发布：联网搜索与文件上传到来，命令行全面开放

🗓 发布：2026-07-20 ✍ 作者：天择网

这是 2.x 系列里功能密度最高的一次更新。天择OS 2.5 围绕"AI 更能干、命令行更通用、系统更顺手"三条线推进：AI 对话首次支持联网搜索和图片/文件上传，命令行从"AI 的专属工具"扩展为"整个系统与所有软件的通用入口"，并一口气修掉了清空对话丢回复、关窗中断生成、生成时无法上滑、Markdown 加粗失效这四个高频痛点。

一、AI 对话：能联网、能看图、能读文件

联网搜索：在「AI 配置 → 能力设置」打开"支持联网搜索"后，对话默认带上搜索工具——问天气、新闻、实时价格这类问题时，模型会自动联网检索并结合结果作答、标注来源。接口不支持时会自动关闭并降级为纯对话，不会报错卡死。

图片与文件上传：输入框新增 📎 按钮，也可以直接把截图、照片、文档 Ctrl+V 粘贴进输入框自动上传。图片按视觉模型方式发送，文件以 base64 文本随消息发出，发送前都能逐条预览和移除。

四个老大难一次修清：①命令行清空对话后，AI 的最后一次回复会保留在屏幕上，不再"话音刚落就被清掉"；②关掉对话窗口，正在生成的回答会继续跑完并存入历史，重开窗口就能看到，不再人走茶凉；③生成过程中可以自由上滑翻历史，只有当你本来就在底部时才会自动跟随滚动；④Markdown 加粗终于正常渲染（此前 ** 会被斜体规则误吞），并补齐了链接、图片、删除线等格式。

二、AI 配置：把"能力"说清楚，把"用量"摆出来

新增一组能力设置：图片输入（关闭则截图功能同步禁用）、文件输入、联网搜索、上下文长度。按你的模型与服务商实际情况勾选，不支持的功能保持关闭，可以避免报错和白白烧 token。填了上下文长度后，对话工具栏会实时显示"已用 / 总量"百分比，快满了心里有数。

模型填写也更省事：点"📥 获取模型列表"，系统会用你的接口地址和 Key 调一次 /models，把服务商支持的全部模型拉成下拉列表，点选一个即可，当然仍可以手动自定义。配置页整体改为左右分栏，接口与能力在左、价格与记忆在右，一目了然。

三、命令行：从 AI 的工具，变成整个系统的入口

这是本次最有想象力的改动。命令行新增：openurl（在内置浏览器打开网页）、clock / stopwatch / timer（时钟 / 秒表 / 倒计时，支持 timer 5m 这样的自然写法）、coc-data / words（一键返回你的 COC 数据、单词库）、ask（让 AI 回答指定问题，出于安全考虑仅用户可用、AI 不能调用）。

更关键的是软件命令包：任何已安装软件（包括你自己用软件商城生成的软件）都可以注册自己的命令，之后用 cmd 应用id 指令 参数 直接操控——比如给你的 markdown 笔记软件注册一条 note 命令后，命令行输入 cmd 笔记id note 今天学了量子力学 就能把这句话记进笔记。配套的 installhelp 命令会返回完整的接入教程，也已写进软件商城的生成提示词，让 AI 生成的软件天生就会"听命令"。

四、系统体验：阅读器、时钟、状态栏、单实例

新增文档阅读器，支持 Word（docx）、PPT（pptx）、Excel（xlsx）、PDF、HTML、txt、markdown，点选或直接把文件拖进窗口即可阅读。新增时钟应用，集时钟、秒表、倒计时于一体。任务栏右下角现在显示电量与联网状态。同一种软件从此只开一个窗口——重复点击图标不会再开第二个造成设置冲突，而是自动跳到已经打开的那个。浏览器里部分链接（如 B 站搜索）点了没反应的问题也已修复。

五、界面：更顺滑的动效

在完全保留紫-蓝-绿品牌配色的前提下，对全系统做了一次动效润色：图标与按钮的悬停位移、阴影、弹性缓动都更细腻，窗口与列表的进入更自然，整体少一点生硬、多一点跟手。

六、历史版本归档

/os 主页新增了完整的更新日志与历史版本下载区，1.0 到 2.5 的演进一目了然；1.0 / 2.0 / 2.1 / 2.2 / 2.5 的桌面版安装包均已归档，可随时回溯。

网页版用户下次启动天择OS 即自动获取 2.5；桌面版用户请前往天择OS 入口获取新版安装包（首次安装或覆盖升级均可，本地存档不会丢失）。
