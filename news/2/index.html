AI 专区上线「技能」板块，首个技能「课本学习助手」可在线体验

🗓 发布：2026-07-09 ⏰ 时间：14:55（UTC+8） ✍ 作者：天择网

AI 专区今天新增了「技能」二级专区，并上线了第一个技能——textbook-learning-helper（课本学习助手，TLH）。这是一个能把教材章节一键转化为可离线打开、可与 DeepSeek 对话的交互式 HTML 学习页的技能，版本 L7.0，由「物竞天择」开发并完全开源。

这个技能做什么

把教材某章/节喂给 AI，它会生成一个自包含的 HTML 学习页：两栏布局，左栏可切换「知识点 / 教材原文 / 测验 / 错题本 / 批阅数据」五个视图，右栏是 DeepSeek AI 对话。每个知识点强制附交互式演示，测验覆盖六大题型（单选/多选/不定项/判断/填空/解答），客观题本地判分、主观题 AI 批阅。

它把「读教材—理知识点—做题—对答案—问 AI」这条完整学习闭环，浓缩进一个 HTML 文件里。

本次上线的三块内容

挂载位置：AI 专区 → 技能 → 课本学习助手。专区内提供：

  • 三级专区主页：技能简要介绍、功能定位与适用场景、核心功能卡片。
  • 使用教程（tlh/about/）：API 文档级别的详细说明，涵盖六步生成流程、五个源文件字段规范、六大题型输入输出格式、公式与演示书写规则、inject.py 参数与行为。
  • 在线体验：填入你自己的 DeepSeek API Key 即可在网页里直接体验——预设教材为「狭义相对论入门教学」，已用本技能生成完整学习页（8 个知识点、8 个交互演示、8 道题）。

在线体验与安全说明

体验区提供 API Key 输入框。需要特别说明的是：本网站是纯前端站点，没有服务器，你输入的 Key 只会保存在你的设备（浏览器 localStorage）上，用于把 Key 注入到演示学习页里启用 AI 对话与批阅功能，不会上传到任何地方。如果你仍不放心，也可以下载技能包在本地使用。

此外，专区还提供技能压缩包的直接下载入口，下载后放入你的 AI Agent 技能目录即可生成任意章节的学习页。

接下来

这是 AI 专区「技能」板块的第一个技能。后续若有新的实用技能，会继续在这里上线。欢迎前往 课本学习助手专区 体验，或阅读 详细使用教程。
