天择网与天择OS 5.0：网页浏览、文件管理与本地模型

发布：2026-08-07 作者：天择网

网页在浏览器里、文件散在各处、知识库和模型又各有入口，功能不少，切换起来却很累。天择网与天择OS 5.0 正式发布，这一次把网页浏览、文件、知识库、云端与本地模型，以及 Windows 工具真正集中到了一起。

这次真正聚到一起的东西

  • 桌面版使用真正的网页窗口，可以打开拒绝嵌入的网站，也能直达多个网页版人工智能服务。
  • 文件空间统一管理浏览器下载和知识库文件，并支持导入、预览、编辑、搜索与回收站。
  • 人工智能可以按需使用云端或本地模型；云端临时不可用时还能自动切换，同时自动识别本机模型、精简长对话占用。
  • Windows 版新增应用管理器和内置 Python；COC 分享配置与教程入口也同步得到完善。

先在线体验，还是直接装桌面版

想先看看整体变化，可以打开网页版 5.0体验；如果需要在桌面中打开完整网页、管理本机文件、安装应用或运行 Python，请从下载页安装桌面版。
