天择网与天择OS 4.0 正式发布：从 3.5 工作台到全站智能星图

发布：2026-07-31 作者：天择网

天择网与天择OS 正式进入 4.0。相较旧版天择网和天择OS 3.5，这次更新不只是增加几个入口，而是重建了整套网站结构、桌面工作台和 AI 使用方式。3.5 已有的等级积分、AI 记忆、联网开关、命令行、附件、OCR、三套配色和本地数据能力全部保留；4.0 在这些基础上统一视觉、重组信息架构、强化多任务与检索，并把隐私和权限边界写进功能流程。

一、旧版天择网升级为统一的 4.0 工作区

全站公共导航、页头、卡片、按钮、弹窗、搜索、空状态和页脚被统一到新的 Evolution Network 设计系统。主要专区采用左侧约三分之一说明、右侧约三分之二内容的分栏工作区：左侧负责定位与上下文，右侧集中实际工具、数据和文章；窄屏会自动折叠为单栏，不牺牲阅读顺序。

新闻、博客、数据开源、AI 技能、COC、游戏、英语、天择OS 和联系页都完成了适配，专业工具仍保留自己的内容气质。滚动、悬停、页面进入和工作区切换使用同一套克制的动态语言，并补齐键盘焦点、图标尺寸、无障碍名称和横向溢出约束。最终验收覆盖 53 个桌面页面和 8 个移动页面，横向溢出、零尺寸图标和歪斜图标均为 0。

二、冷、中、暖三套配色成为完整视觉系统

3.5 引入的冷、中、暖配色在 4.0 中扩展为完整主题，而非只替换色值：

  • 冷色：紫、蓝、绿，突出深空、秩序与数字工作台质感。
  • 中性：蓝、绿、黄，在信息密度和活力之间保持平衡。
  • 暖色：绿、黄、橙，让高频操作区域更明亮、更有温度。

每套主题都拥有对应的生成式星图壁纸、表面纹理、按钮材质和图片图标表现。OS 核心图标改用统一生成式图集，网站和桌面共享一致的形状与语义规范；重要动作仍保留文字和可访问名称，避免只靠颜色或图片传递含义。

三、首页变成 28 节点同心放射星图

旧首页的静态目录区被替换为由站点索引实时生成的28 节点精选同心星图。首页位于中心，一级专区环绕核心，二级和更深层页面分布在外轨，并通过连线表达归属。新闻和博客各精选最多 5 条，完整历史仍保留在栏目页和检索索引中。

悬停或键盘聚焦节点时，目标及邻近节点按距离平滑放大；标题始终可见，点击直接进入页面。星图由 buildOrbitMap() 根据索引生成，不再维护容易误导用户的旧六节点静态兜底。

四、天择OS 桌面、窗口和应用界面全面重构

天择OS 4.0 重新组织顶部系统状态、左侧快捷轨道、桌面分类、任务栏、开始菜单、窗口标题栏和应用入口。浏览器、文档阅读器和 AI 对话将标签页合并进标题栏，减少重复工具条；普通窗口、置顶窗口、快捷面板、悬浮窗和模态框继续遵守明确层级，最大化和滚动状态也得到统一处理。

系统设置、等级与外观、AI 配置、软件商城、终端、时钟、笔记、浏览器、文档阅读器以及站内工具都换成一致的工作区组件。桌面网页版和 Electron 版继续共用同一套 OS、COC、英语与共享资源，版本保持 4.0.0。

五、AI 多会话、智能命名与可靠后台生成

AI 对话从单一历史升级为浏览器式多会话标签。不同会话可独立新建、切换和关闭，生成过程中切换标签不会把回复写入错误会话；后台完成后仍会保存到原会话。首轮问答结束后，系统会尝试生成简短中文标题，失败也不会影响对话正文。

上下文用量、停止生成、编辑重发、重新生成、思考过程、LaTeX、附件、截图、记忆和 Agent 轨迹继续可用。4.0 进一步加固了异步会话归属、跨窗口同步、流式降级和工具调用回执，避免关闭窗口或切换标签导致回复丢失。

六、模型预设、能力门控、费用与联网控制

AI 配置整理了 DeepSeek V4 Flash、DeepSeek V4 Pro、MiMo V2.5、GLM 4.7 Flash、GLM 4.6V Flash 等预设，并记录上下文长度、最大输出、图片输入、联网搜索和费用估算能力。自定义 OpenAI 兼容接口仍可使用；用户还可以在三个本地槽位中保存整套自定义 AI 配置、自行命名并一键切换，接口、模型、能力、上下文、费用与 API Key 会随槽位保存。

三个自定义槽位及其中的密钥只保存在当前设备的 localStorage；配置卡片不会展示密钥。完整系统存档会包含这些本地配置，因此导出文件也需要由用户自行妥善保管。

对话工具栏按当前模型能力动态显示：不支持联网的模型不出现联网按钮，不支持图片的模型自动使用本地 OCR，支持视觉输入时才发送原图；联网搜索仍需用户在能力设置和当前会话中主动开启。服务端拒绝联网工具时会自动关闭本轮联网并降级重试，避免整段对话直接失败。

七、本机优先 AI 知识库与统一检索

4.0 新增本机优先的混合知识检索。站内 52 个可检索页面、天择OS 笔记、历史会话，以及用户主动加入的文档会进入统一召回流程；系统结合关键词、中文片段、字符模糊相似度和资料时间排序，并要求回答标注来源标题和更新时间。

文档不会因为打开就自动入库。用户需在文档阅读器中点击「加入 AI 知识库」，再次点击即可移除；支持从 PDF、Word、PPT、Excel、HTML、Markdown 和文本中提取可检索文字。扫描版 PDF 在文字层不足时会逐页进入本地 OCR，并显示页数、当前页和识别进度；首次使用需要下载识别组件，识别过程和结果仍留在本机。

AI 对话工具栏新增知识库设置按钮，以 4 列 × 3 行矩阵分别控制站内页面、本地文档、本地笔记和历史会话。每个来源可选「完全不参考」「自动匹配」「完整注入」之一；完整注入超出当前模型上下文安全预算时会明确截断。独立的「知识库管理」软件可以查看现有条目、来源模式、标题、更新时间、文字量和正文摘要，并可将本地文档移出知识库。

正文保存在本机 IndexedDB，检索也在本机完成。自动匹配只把命中的短摘录发送给当前配置的模型；完整注入由用户主动选择，并受当前模型上下文预算保护。

八、天择网站内 AI：懂页面，但没有桌面权限

天择网页面新增独立悬浮助手，可读取当前页面摘要和候选导航，并结合全站索引与本机知识回答问题、返回准确的站内 Markdown 链接。它与天择OS 共享 AI 配置和能力描述，但使用独立会话记录，不会把网站问答混入 OS 对话。

站内助手可以在模型允许且用户开启时联网，也能按操作读取当前网页截图；但它不具备命令行和桌面 Agent 权限，不能借网页问答操作系统。页面上下文、截图和本机命中摘录均按本轮请求提供，不自动获得更大的权限。

九、OCR、截图与附件链路重新优化

网页截图和普通文档图片不再共用一套固定预处理。系统会按场景进行高质量缩放、自适应灰度、对比度和深色界面转换，减少白字、细字及稀疏布局的漏识别；中英文引擎复用同一工作线程，多图按队列处理并显示实际进度，降低重复加载带来的内存峰值。

纯文本模型收到的是本地 OCR 文字而不是原图；文本类附件直接读取正文，视觉模型才接收图片。能力门控、大小限制和失败降级保持一致，从而让「能不能发」「实际发了什么」更可预测。

十、Agent 权限与 Windows 悬浮窗桥接

Windows 桌面版的独立 AI 悬浮窗可在用户开启 Agent 模式后，把单条命令委托给主窗口执行。真正的命令行和窗口管理仍由主天择OS负责，结果回到原会话继续推理；桥接校验来源、命令长度、并发状态和超时，不允许站内 AI 复用。

AI 生成软件继续通过受控命令注册表调用系统能力，终端长输出自动折叠，命令结果按轮次显示。网站问答、普通 AI 对话和桌面 Agent 被明确分层，减少「回答问题」意外升级为「执行操作」的风险。

十一、英语学习工作台完成四阶段重构

背单词从旧式工具页升级为词库控制、训练舱、数据台和复习队列四个工作区。训练仍遵循英译中预习、中译英回忆、英译中巩固、完整拼写的闭环，并保留自定义词库、AI 例句、AI 解析、本地统计和错词复习。

大词库继续使用 IndexedDB 和分批让出主线程，避免导入卡死；桌面 OS 的无浏览器外壳模式也修正了吸顶偏移，最大化和滚动时导航不会遮挡训练标题。

十二、COC 工作台、升级规划与伤害计算继续演进

COC 首页、数据查询、升级规划器和伤害计算器统一换成新的专业工作区。村庄存档继续在本机解析，并可向升级规划和伤害计算提供完整装备、法术、建筑与建筑工人小屋等级；主存档保持富格式，避免不同工具互相覆盖。

伤害计算继续支持最高伤害、最少法术、自定义闪震、英雄装备技能伤害、建筑工人小屋回复与回血容错，并遵守储罐、大本营、部落城堡和城墙的免疫规则。计算结果可以生成公开网页只读分享链接，链接固定使用 https://wjtianze.github.io/coc/dmg-calc/index.html#share=…，只编码本次配置，不读取或改写接收方本地存档。

十三、AI 技能、游戏、开源和内容页面同步更新

AI 专区及在线技能页面统一为新的工作区结构；词库转 JSON、COC 数据导出等工具继续保留。游戏专区与《绩点战争》重排界面和状态卡片，数据开源页、联系页、新闻和博客补齐相同的视觉、导航与移动端规则。

受保护的 TLH 相对论演示保持原始交互与文件内容不变。开源源码包仍由发布同步流程生成，网站下载页只展示真实存在的 GitHub Release，不用占位地址冒充可用安装包。

十四、缓存、版本、隐私与可恢复性

全站资源缓存更新至 20260801-v4.1.6，OS 资源缓存更新至 4.0.5-ui414；网页版本、桌面 package.json 与锁文件均保持 4.0.0。站点索引可重复构建，桌面资源由唯一网站源码复制，发布副本也由安全同步脚本生成，减少多个副本人工漂移。

AI 配置、聊天、笔记、词库、COC 存档、等级积分和知识库继续采用本地存储，并保留存档导入导出路径。联网、截图、文档入库和 Agent 都需要清晰的能力或用户动作；失败时优先降级、保留原始数据，不把「功能不可用」变成「数据丢失」。

十五、如何体验 4.0

天择OS 网页版可直接体验新桌面、三套配色、多会话 AI、本机知识库和新版应用。Windows 安装包的公开状态以 天择OS 下载页与 GitHub Releases 为准；安装包当前未进行代码签名，Windows 可能显示 SmartScreen 提示。

也可以从 天择网首页开始，在 28 节点同心星图里浏览整座站点，或打开右下角站内助手，直接询问某项内容和工具位于哪里。
