全站升级

天择网全站 UI 重构完成：高级科技杂志式体验正式上线

🗓 发布：2026-07-14 ⏰ 时间：10:42（UTC+8） ✍ 作者：天择网

天择网完成了迄今规模最大的一次界面重构。在保留原有配色的前提下，主站被重新设计为更有层次的高级科技杂志式界面：标题、信息密度、内容网格、卡片表面、按钮反馈和空间节奏都经过重新梳理，网站的各个板块终于拥有了一套统一而清晰的视觉语言。

普通页面：从“页面集合”变成统一的网站

首页、新闻、博客、数据开源、AI 专区、COC 专区、游戏专区和 404 页面全部完成升级。新版强化了内容层级与编辑式排版，让重要信息更容易被看到，同时保留原有内容和访问路径，不用重新学习网站的使用方式。

公共导航也进行了完整重构：移动端菜单会正确反馈开关状态，支持点击外部和 Escape 键关闭；键盘焦点更清晰，关闭菜单后会回到原按钮。背景视差和页面动效不再互相覆盖，并会在系统开启“减少动态效果”时自动降级。

COC 三大工具：信息密集，但不再拥挤

游戏数据查询、村庄存档分析和升级规划器拥有了统一的工具型界面。分类筛选、搜索、数据卡、详情弹窗、结果区、标签页和甘特图都重新组织了信息层级，并补充了键盘操作、焦点管理和状态播报。

升级规划器在重构期间还修复了三项排程逻辑：同槽任务冲突判断、前置依赖结束时间约束，以及英雄数量超过专用工人槽时的重叠问题。现在自动排程与拖动后的结果更加可靠。

《绩点战争》：战术控制台式界面与核心规则修复

《绩点战争：GPA 4.3》从普通网页游戏界面升级为战术控制台：玩家、AI、阶段、手牌、商店、技能和战况日志被重新放入更清晰的战场布局；手机端的手牌与商店改为横向滑动，复杂信息在小屏幕上也能保持可玩。

发布前复验发现并修复了玩家行动阶段不可达、护盾提前清空、后手补偿未实现和 AI 连续出牌索引漂移等核心问题。现在先手首回合为 3 能量，后手首回合为 4 能量；之后每个自身回合正常补给 3 能量，护盾会保留到对手行动并在持有者下次回合开始时清空。

TLH：只升级外层入口，演示界面保持原版

课本学习助手的介绍、API Key 输入和在线体验入口随主站完成了视觉升级，但狭义相对论演示界面本身完全保持原版，没有改变任何一个字、布局或交互。发布前已通过二进制和 SHA256 校验确认其与原版逐字一致。

验证与兼容

本次更新完成了全站本地链接检查、核心 JavaScript 语法检查、COC 规划器定向逻辑测试、绩点战争先后手与回合交替测试，以及 TLH 演示页原版一致性校验。普通页面也对桌面、平板和手机宽度进行了响应式检查。

配色没有变，内容没有被重写，但天择网从视觉、交互到复杂工具的可用性都重新做了一遍。欢迎从 新版首页 开始浏览，或直接体验 COC 数据查询 与 绩点战争。
