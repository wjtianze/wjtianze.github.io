COC 专区新增村庄存档分析与升级规划器，解析脚本开源

🗓 发布：2026-07-13 ⏰ 时间：19:09（UTC+8） ✍ 作者：天择网

天择网 COC 专区今天迎来一次大幅扩展：新增「村庄存档分析」与「升级规划器」两个功能页，并开源配套的村庄 JSON 解析脚本 village_parser.py。现在你可以在浏览器里粘贴自己的村庄存档，一键看清家底、算出升级时长、再用甘特图排出完整的升级计划。

村庄存档分析：粘贴即解析

把游戏中导出的村庄 JSON 粘贴到文本框，页面会自动按「家乡」与「夜世界」两个维度分类展示完整村庄信息——英雄、兵种、攻城机器、法术、战宠、英雄装备、建筑、陷阱、帮手各自独立分区，升级中、改造、武器、超级兵等状态都有标注。

页面上方是剩余升级时间总览：基于你当前的大本营等级，逐级累加每项单位到满级的升级时长，并按资源类别（建筑工人 / 研究员 / 战宠研究员）汇总。最关键的是墙钟时间——串行总时长除以对应的工人或研究员数量，得到并行后真正需要等待的时间。

升级规划器：稳本与速本两种模式

分析页底部进入升级规划器，家乡与夜世界分 Tab 独立排程。横轴是绝对日期，纵轴是资源泳道，每条泳道的进度条数量等于该资源的工人/研究员数量（例如 6 个建筑工人就开 6 条槽并行）。

  • 稳本模式：升级全部内容。建筑工人优先升级英雄，然后是时间短的项目，最后是时间长的项目；研究员随机升级兵种与法术。
  • 速本模式：忽略防御建筑、建筑工人小屋升级、陷阱、资源采集器与英雄，把所有资源集中用来冲大本营。

点「一键全排程」自动把所有任务安排到最早空闲的槽位，也可以手动选择单个任务添加。甘特图里的色块支持拖拽微调起止时间，系统会自动校验同槽位冲突并吸附到最近合法位置。还可以勾选「哥布林工人」「哥布林研究员」加成，实时增加对应槽位。

解析脚本开源

村庄 JSON 的解析与升级时间计算逻辑，已整理成可独立运行的 Python 脚本 village_parser.py。命令行运行 python village_parser.py 村庄.json 即可输出结构化中文报告。脚本已开源在天择网「数据开源」页，村庄分析页底部也可直接下载，免费、不限用途。

同时，AI 专区的开源技能 coc-units-data-exporter 也已更新：技能包现在包含两个脚本——原有的 coc_pipeline.py（从 APK 提取单位数据）与新增的 village_parser.py（村庄存档解析）。

关于数据与隐私

所有解析都在你的浏览器本地完成，村庄数据不会上传任何服务器。升级时间数据来自天择网已开源的《部落冲突》单位完整数据（272 条，数据版本 v18.400.9），升级时长按游戏内实际数值逐级累加，建筑与兵种两套不同的时间语义已分别正确处理。

规划器重大升级（21:51 更新）

上线当天，升级规划器迎来一次重大升级，让它从粗粒度排程变成真正可逐级规划的工具：

  • 单级拆分：每级一个独立滑块（如蛮王 67→75 拆成 8 个），前置依赖自动处理——同单位逐级、兵种/法术需实验室等级、英雄需英雄殿堂等级、战宠需战宠小屋等级。
  • 英雄优先专用槽：几个英雄在升就留几个建筑工人专升英雄，一级接一级连续升级不被打断；工人不够时所有工人优先给英雄。
  • 正在升级锁定：时间轴从村庄 JSON 采集时刻起算，正在升级的项目用剩余时间显示并锁定钉板（🔒），不能拖走。
  • 多座建筑独立进度条：7 座箭塔、6 座加农炮等各自独立展开（箭塔#1…#7），不再合并成 1 个。
  • 缩放与拖拽：最大 4000% 缩放、日期标签随缩放自适应疏密；滑块可在甘特图内拖动改时间，或拖到待规划区移除。
