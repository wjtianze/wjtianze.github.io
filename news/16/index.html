天择OS 2.0 发布：AI 全链路升级，25 项改进一次到位

🗓 发布：2026-07-18 ✍ 作者：天择网

天择OS 今天正式跨入 2.0 时代。本次大版本围绕「AI 更好用、系统更顺手、浏览器更能打」三条主线带来 25 项新功能与修复，并同步修正了 COC 专区的 4 处数据问题。自 2.0 起，天择OS 每次发布更新都会递增版本号，系统启动时自动检查新版本，也可在「系统设置 → 系统版本」手动检查更新。

一、AI 对话：看得见、停得下、可重来

深度思考全程可见：AI 对话、软件商城生成、AI 改进等所有场合，推理模型的思考过程都会实时展示（可折叠），不再黑箱。

LaTeX 公式实时渲染：公式随流式输出即时渲染，不再等整段答完才出现（与 TLH 课本学习助手同一套渲染机制）。

停止 / 重新生成 / 编辑重发：生成中点 ⏹ 随时停止并保留已生成部分；AI 消息可「⟳ 重新生成」，你的消息可「✏️ 编辑重发」——注意，重新生成或编辑重发后，该消息之后的所有消息都会被删除。

token 用量统计：每条 AI 消息下方显示本次消耗的 token 明细（缓存命中 / 缓存写入 / 普通输入 / 输出 / 总量），成本一目了然。

AI 记忆：AI 现在会记住关于你的事实（如「用户是大学生」）。「AI 配置 → AI 记忆」里可手动增删改每条记忆、逐条或批量开关是否注入提示词，也可开关「生成后自动写入记忆」。

二、软件商城：代码更长、更干净、更聪明

自动续写：输出触及 token 上限时自动断点续写（最多 3 次），「代码写到一半就停」成为历史；「AI 配置」中还新增了最大输出 Token 自定义项。

只出代码：提示词全面加严并配代码清洗，彻底杜绝「好的，以下是你要的 html」这类寒暄混入。

生成即能用：提示词内置 KaTeX 公式、Markdown 渲染与 localStorage 本地存储的写法教程，生成的软件自动具备这些基本功；你的 AI 配置（URL / Key / Model）也会写入提示词，想要带 AI 功能的软件开箱即用。

深度思考状态透明：生成过程会显示当前生效模型与深度思考开关状态，修复了豆包模式下「尚未配置 API Key」的误报——所有 AI 功能现在始终使用「AI 配置」里的通用配置。

三、系统体验：主题、桌面与导航

浅色 / 深色主题：任务栏 🌓 按钮或系统设置一键切换，全系统即时生效。

Windows 风格补完：窗口的最小化 / 最大化 / 关闭按钮改为真正的 Windows 样式（矩形悬停高亮，关闭悬停放红）；任务栏最右端新增「显示桌面」细条，点一下最小化全部窗口，再点复原；Windows 任务栏与 macOS Dock 高度统一为 52px。

天择导航树：新增「🌳 天择导航」应用，专区 / 二级专区以树状图直观呈现，点击即开。

开始菜单分类：应用按分类分组显示，不再一股脑堆叠；快捷面板关闭后的小悬浮球现在可以随便拖。

四、浏览器：标签、收藏与链接

标签页栏并入标题栏：浏览器标签页与窗口标题栏合并，标签直接显示网页自带的标题。

收藏夹书签：☆ 收藏当前页，📑 管理收藏；支持导入 / 导出书签文件，兼容 Chrome / Edge / Firefox 的 Netscape 书签格式。

外链修复：网页里的 window.open 按钮在 OS 内不再「点了没反应」，一律转为系统内新标签页打开；点击网页区域即视为点击了该应用，窗口自动置顶、Ctrl+Q 全屏等快捷键恢复生效。

五、新应用：Windows 模拟器 & 安卓模拟器

桌面新增「模拟器」分类，内置两款免费、纯浏览器运行的真实 x86 模拟器（基于开源 v86 项目）：Windows 98 与 Android x86，开机即用。

六、数据与配置：一个都不少

全量存档：存档导出 / 导入现在覆盖本机全部数据——AI 配置、系统设置、已装软件、对话历史、收藏夹、AI 记忆、背单词等天择网各应用数据（localStorage + IndexedDB）。

AI 配置统一：天择背单词及今后所有需要 AI 的天择网功能，在天择OS 内一律自动使用 OS 的通用 AI 配置，不再单开配置。

七、COC 专区同步修正

① 伤害计算器补上助燃器与火箭背包两件装备的技能伤害（数值取自游戏原始数据与公开装备表）；② 数据查询页的装备详情现在完整展示主 / 副技能的全等级数据表；③ 附属单位（如小戈仑石人）不再单独成卡——概览中并入主单位卡片下部，详情中显示在主单位右侧并带「附属单位」标识；④ 伤害计算器按真实机制处理法术免疫：资源储罐（储金罐 / 圣水瓶 / 暗黑重油罐）对所有法术免疫，部落城堡与大本营对雷电免疫但不免疫地震；顺带修复了按大本营等级一键填充时大本营自身等级错位的问题。

打开 天择OS 体验 2.0，或在系统内「玩机技巧」查看全部新功能用法。网页版用户下次启动即自动获取更新。
