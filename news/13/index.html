英语专区与天择背单词正式上线：从词汇训练开始

🗓 发布：2026-07-15 ✍ 作者：天择网

天择网今天正式上线英语专区。这是一个围绕英语学习建立的新板块，定位是「按需生长的学习工作台」——不绑定于单一方向，而是随真实学习需求逐步扩展工具。首期同步上线专区核心工具天择背单词，正式路径为 /english/words/。

英语专区：以词汇训练为起点

英语专区不只是一个背单词入口，而是一个会持续容纳学习工具的工作台。现阶段它的核心是词汇训练，用四阶段学习法把词义辨认、主动回忆和准确拼写连接成完整闭环；后续会随学习进度逐步补充新的训练模块。专区首页介绍整体定位与学习流程，并提供天择背单词的正式入口。

四阶段学习闭环

专区采用循序渐进的四阶段学习理念，每个阶段都对应一种不同的记忆任务：

  • 英译中预习：先观察英文、音标和词义，建立最初的词形与语义联系。
  • 中译英回忆：看到中文后主动提取英文，避免只形成被动识别。
  • 英译中巩固：通过选择题辨析正确释义与干扰项，强化容易混淆的含义。
  • 完整拼写：根据释义输入整个单词，用输出训练检验最终掌握程度。

从理解、回忆到辨析和拼写，四个阶段组成一次完整学习闭环。学习者可以清楚看到自己在哪种任务中出错，而不是只得到一个笼统的「认识」结果。

自定义 JSON 词库与一词多义

天择背单词首次启动时不预置固定词库，学习者可以导入文件或直接粘贴自己的 JSON 数据。每条记录支持单词、音标、词性、释义、例句和标签；其中释义以数组保存，因此同一个单词的多个含义可以独立保留，不会在导入时被压缩成一条模糊说明。词库可搜索、导出或清空，也可以查看总词数、已学、错词与已掌握数量。

进度统计与错词本

应用记录已学单词、正确率、连续学习天数和掌握度，并展示近 14 天学习曲线与掌握度分布。答错的词会进入错词本并按错误频率排序，可直接开启专项重练；连续答对 3 次后会自动移出错词本。

AI 出题、例句与深度解析

配置 OpenAI 兼容接口后，可以启用 AI 干扰项，让选择题不再只依赖本地词库随机抽取；也可以为单词生成例句，并在词库、答题反馈和错词复习中请求更深入的解析。应用内置 DeepSeek、OpenAI、硅基流动和智谱 GLM 的接口预设，也允许自定义 API 地址与模型名。

与 AI 词库技能联动

英语专区同时与 AI 专区的 vocab-to-json（词库转 JSON）技能联动。它可以读取 TXT、CSV、XLSX、DOCX、PDF 与 Markdown 中的单词资料，整理单词、音标、词性、释义和例句，处理一词多义与重复项，并输出天择背单词可直接导入的标准 JSON。这样，纸质资料整理出的表格、老师发放的文档或个人积累的词表，都可以先通过技能转换，再进入英语专区训练。

学习数据保存在浏览器本地

词库、学习进度、统计、错词本和 AI 配置均保存在当前浏览器的 localStorage 中，不经过天择网服务器。更换浏览器或设备时数据不会自动同步，清理站点数据也会删除本地记录；需要迁移词库时可先使用导出功能保存 JSON。

前往 英语专区 查看学习流程，直接在 天择背单词 开始训练，或在 词库转 JSON 技能页 把已有资料整理成可导入词库。
