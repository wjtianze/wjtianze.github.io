天择背单词正式上线：迁移至英语专区，四阶段训练完整开放

🗓 发布：2026-07-15 ✍ 作者：天择网

天择背单词现已正式上线，并从原有独立位置迁移到英语专区。新的正式路径为 /english/words/，专区首页和 AI 词库技能页也已统一指向这个入口。

自定义 JSON 词库与一词多义

应用首次启动时不预置固定词库，学习者可以导入文件或直接粘贴自己的 JSON 数据。每条记录支持单词、音标、词性、释义、例句和标签；其中释义以数组保存，因此同一个单词的多个含义可以独立保留，不会在导入时被压缩成一条模糊说明。

词库可搜索、导出或清空，也可以查看总词数、已学、错词与已掌握数量。若手头只有文档或表格，可先使用 AI 专区的词库转 JSON 技能完成格式转换。

选择与拼写组成四阶段训练

一次学习会依次经过英译中预习、中译英回忆、英译中巩固和完整拼写。前三个阶段通过选择题建立和检验词义联系，最后根据中文释义输入英文拼写；拼写阶段还提供发音与首字母提示。用户可设置每轮单词数，也可只练错词。

进度统计与错词本

应用记录已学单词、正确率、连续学习天数和掌握度，并展示近 14 天学习曲线与掌握度分布。答错的词会进入错词本并按错误频率排序，可直接开启专项重练；连续答对 3 次后会自动移出错词本。

AI 出题、例句与深度解析

配置 OpenAI 兼容接口后，可以启用 AI 干扰项，让选择题不再只依赖本地词库随机抽取；也可以为单词生成例句，并在词库、答题反馈和错词复习中请求更深入的解析。应用内置 DeepSeek、OpenAI、硅基流动和智谱 GLM 的接口预设，也允许自定义 API 地址与模型名。

学习数据保存在浏览器本地

词库、学习进度、统计、错词本和 AI 配置均保存在当前浏览器的 localStorage 中，不经过天择网服务器。更换浏览器或设备时数据不会自动同步，清理站点数据也会删除本地记录；需要迁移词库时可先使用导出功能保存 JSON。

天择背单词的新正式入口是 /english/words/。从自定义词库开始，完成选择、回忆、辨析和拼写的完整训练。
