## 新增专区检查表

1. 用 ImageGen 分别生成约 16:9 的桌面横图和 9:16 的移动端竖图，画面必须包含该专区独有且可辨认的标志性元素。
2. 桌面版将主体放进不易被首屏内容覆盖的边缘安全区；移动版将主体放进中央 85% 安全区。禁止在背景中生成正文、菜单或水印。
3. 分别保存为 `source/<zone>.png` 与 `mobile/<zone>.png`，再生成同名质量 84 WebP；在 `main.js` 的 `initTzSectionIdentity()` 登记专区，并在 `style.css` 同时配置桌面和移动 WebP 变量。
4. 必须实际截图检查 1440×900、390×844 两种视口；标志性元素应在页面内容叠加后仍可辨认，正文对比度必须足够。
5. 若专区也进入天择OS，同时检查 `PRESET_APPS` 与 `TZ_TREE`。

背景仅表达专区身份，不承担导航和文字信息；品牌 Logo 只作为环境标志使用，不伪造官方联名或背书。
