网页端、普通桌面版与 Codex 桌面版数据各自独立，可按需并存。网页端只能使用普通 API 版；Codex 版仅适用于 Windows 桌面。
普通版默认使用 Cloudflare 后端托管的 Gemini 3.7 Flash 免费模型，无需在前端填写 API Key；主模型限流时后端立即改用智谱官方 GLM 4.7 Flash 免费模型，断线或其它瞬时故障则在安全重试用尽后切换。回退使用独立服务通道，但免费服务仍受平台策略与容量影响，不代表无限调用。需要其它模型时仍可在“AI 配置”中添加自己的接口。Codex 版请在“Codex 管理”中登录自己的 ChatGPT 账号。安装包未进行商业代码签名，Windows 可能显示 SmartScreen 提示；高权限操作仍受 Codex 审批与系统权限约束。
